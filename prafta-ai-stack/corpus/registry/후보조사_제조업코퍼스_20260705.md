## 접근 한계 / 미확인 사항

1. **API 응답 스키마 미검증**: 15119137·15121001·15121008·15144147은 활용신청(인증키) 후 호출 가능 — 이번 조사에서는 상세 페이지의 파라미터·설명까지만 확인. 출력 필드 확정은 키 발급 후 샘플 호출 필요.
2. **KOSHA 재해사례 첨부파일 원문의 공공누리 유형**: API 라이선스는 "제한 없음"이나, 첨부 문서 자체에 별도 저작권 고지가 있을 수 있음 — 인제스트 전 문서 1~2건 육안 확인 필요.
3. **KOSHA GUIDE PDF 본문의 이용조건**: API 페이지에는 표기 없음 — 미확인.
4. **크레인/화물차 미디어자료(15100764/15100762)**: 지게차(제2유형)와 동일 시리즈로 추정했으나 개별 페이지 라이선스는 직접 확인하지 않음.
5. data.go.kr 검색 결과 중 한글(HWP) 전용 자료·MP4 영상 자료는 코퍼스 부적합으로 상세 확인 생략.
