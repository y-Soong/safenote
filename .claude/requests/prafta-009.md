\## Attd\_07.vue, AttdDayDetailPop.vue 화면 테스트 요청 및 추가기능 개발의 건



\# AttdDayDetailPop.vue 화면 추가기능 개발 요청

1. 아마 지금 근로자의 근태 생성/수정 및 추가근무 생성/수정 요청에 대한 반려 기능이 미개발된 상태일텐데 확인 후 맞다면 해당 부분 개발 요청

   1. 관리자가 근로자의 요청 반려 시 TB\_USER\_ATTD\_REQ 테이블에 해당되는 요청 데이터의 상태값 변경 후 TB\_USER\_ATTD\_HIST에 관련 이력을 남겨주면 됨
   2. 혹시 추가적으로 처리될 부분이 있다면 채팅으로 질문 후 이어서 진행
2. 근로자의 외근지 근무에 대해서 GPS 상에서 좌표를 볼 수 있는 기능 개발 요청

   1. 근로자의 외근지 근무는 TB\_USER\_ATTD\_GPS 테이블의 ATTD\_ID와 TB\_USER\_ATTD\_MGMT 테이블의 ATTD\_ID를 비교하여 값이 있을경우 외근지 근무로 간주하면 됨
   2. 1구간, 2구간 근무별로 버튼을 통해 조회할 수 있는 기능이 있어야하며 해당 테이블의 LAT, LON 값을 기준으로 출근,퇴근에 대한 정보를 카카오맵에 좌표 표시를 해주면 됨

      1. prafta-009\_참고.png 이미지에 빨간색 박스친 부분에 외근에 대한 해당사항이 있을때 옆에 1구간, 2구간 과 동일한 css로 "외근" 버튼이 생기면 됨



&#x20;# AttdDayDetailPop.vue 화면 수정 요청

1. prafta-009\_참고.png 이미지에 초록색 박스친 부분에 초과근무에 대한 합계 정보를 보여주고 있는데 해당 부분 삭제 요청
2. prafta-009\_참고.png 이미지에 파랑색으로 박스친 부분을 보면 등록 가능 시간이 이상하게 표시되어 있음

   1. 원하는 동작 방식은 1구간/2구간 근무는 각각에 매칭되는 스케줄 시간과 등록 가능시간이 계산되어야 하는데 현재는 이부분이 정상적으로 적용되지 않은걸로 보임



\# 해당 화면에 대한 개발이 종료되어 테스트 요청

1. 관리자가 사용자들의 근태 데이터를 정상적으로 생성/수정/삭제 가능한지

   1. 스케줄이 존재하는 경우 / 존재하지 않는 경우
   2. 스케줄이 존재할 경우 1구간 스케줄인 경우 / 1구간 + 2구간 스케줄인 경우
2. 근로자의 근태 생성/수정 및 추가근무 생성/수정 요청에 대해 관리자가 정상적으로 승인해줄 수 있는지

   1. 스케줄이 존재하는 경우 / 존재하지 않는 경우
   2. 스케줄이 존재할 경우 1구간 스케줄인 경우 / 1구간 + 2구간 스케줄인 경우

3\.	상기 AttdDayDetailPop.vue 화면에 대한 신규 기능과 수정요청건에 대해서도 아래 모든 케이스에 대해서 정상적으로 동작하는지 확인

&#x09;1.	스케줄이 존재하는 경우 / 존재하지 않는 경우

&#x09;2.	스케줄이 존재할 경우 1구간 스케줄인 경우 / 1구간 + 2구간 스케줄인 경우
