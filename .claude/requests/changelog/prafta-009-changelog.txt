[2026-05-17] TB_USER_ATTD_REQ.REQ_TYPE 컬럼 길이 확장 — PRAFTA-009 마무리
  대상 DB : 로컬/개발 (jdbc:mysql://localhost:3306/prafta, 계정 dev_prafta)
  적용 파일: .claude/migrations/prafta-009-reqtype-002.sql
  내용     : REQ_TYPE 컬럼 varchar(10) -> varchar(20) 확장.
             COMMENT 도 '요청 유형 (SYS032: 01~06)' ->
             '요청 유형 (ATTD_MODIFY/ATTD_CREATE/OT_REGISTER/LEAVE_REQUEST)' 변경.
  배경     : 기존 varchar(10) 은 11자 'ATTD_CREATE'/'OT_REGISTER' 를 저장 불가.
             QA 재검증 D2 가 미해결로 남은 직접 원인 — selectDailyAttdDetailHistory
             의 orphan 분기(R.REQ_TYPE='ATTD_CREATE')가 영구 미매치였다.
             컬럼 확장으로 D2 가 코드 수정 없이 해소됨(아래 §3 검증 결과 참조).
  적용 전 정의: `REQ_TYPE` varchar(10) NOT NULL COMMENT '요청 유형 (SYS032: 01~06)'
  적용 후 정의: `REQ_TYPE` varchar(20) NOT NULL
               COMMENT '요청 유형 (ATTD_MODIFY/ATTD_CREATE/OT_REGISTER/LEAVE_REQUEST)'
  비고     : REQ_STATUS 는 varchar(10), 최장값 'CANCELLED'(9자) 수용 가능 → 미변경.

  원복 SQL:
    ALTER TABLE TB_USER_ATTD_REQ
        MODIFY COLUMN REQ_TYPE VARCHAR(10) NOT NULL
        COMMENT '요청 유형 (SYS032: 01~06)';
    -- 원복 전 10자 초과 값 부재 확인:
    --   SELECT REQ_ID, REQ_TYPE FROM TB_USER_ATTD_REQ WHERE CHAR_LENGTH(REQ_TYPE) > 10;
