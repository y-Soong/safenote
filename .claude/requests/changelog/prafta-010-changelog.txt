  --- PRAFTA-015 (표준화 시간 계산 버그 수정) ---
  배경: 기존 FNC_STD_TIME 은 표준화 결과가 1440분(24:00) 이상이면 23:59 로 캡하여
        자정 넘김을 표현하지 못한다. 또한 표준화 단위 코드 조회를
        FNC_CMM_INFO_SRCH('ATTD_STD_CHKIN'/'ATTD_STD_CHKOUT', ...) 로 하던
        경로는 TB_ATTD_STD_TIME_RULE_HIS 의 시행일(INSERT_DATE) 기반 최신 룰을
        반영하지 못한다. FNC_STD_TIME 은 ALTER 불가이므로 mapper SQL 재작성으로
        해결한다.

  해결 방식:
    - Attd07Mapper.xml 상단의 SQL 프래그먼트 4종 사용
      (frag_std_unit / frag_std_stamp / frag_std_date / frag_std_time).
      * frag_std_unit  : 근무일자 기준 TB_ATTD_STD_TIME_RULE_HIS 에서
                         STD_TIME_RULE_TYPE(SYS028: 01=출근, 02=퇴근)별로
                         DATE(INSERT_DATE) <= 근무일자 인 행 중 INSERT_DATE 최신
                         1행의 STD_TIME_TYPE(SYS029)을 분으로 CASE 변환
                         (01=0, 02=5, 03=10, 04=15, 05=30). 단위 0=설정안함.
      * frag_std_stamp : 근무일자 00:00 origin 통합 분 stamp
                         (DATEDIFF(체크일자,근무일자)*1440 + 시*60 + 분).
                         단위 0 이면 원본 stamp 그대로. 단위>0 이면
                         출근=CEIL / 퇴근=FLOOR.
      * frag_std_date  : 근무일자 + FLOOR(stamp/1440) 일 -> YYYYMMDD.
      * frag_std_time  : MOD(stamp,1440) 음수 보정 -> HHMM.
      ※ FNC_CMM_INFO_SRCH('ATTD_STD_CHKIN'/'ATTD_STD_CHKOUT', ...) 호출 전량 제거.
    - 3개 select 에 적용:
      * selectMonthlyAttdList   (cmpny=U.CMPNY_CD, ymd=D.WORK_YMD)
      * selectDailyAttdDetails  (cmpny=A.CMPNY_CD, ymd=A.WORK_YMD)
      * selectAllowedWindow     (cmpny=#{gvCmpnyCd}, ymd=WP.WORK_YMD)
    - 표준화 출근/퇴근 일자 필드를 result record 3종에 추가.
