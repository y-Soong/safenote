## TBM 교육 관련 WEB / MOBILE 개발 요청

1. TBM 비즈니스 플로우
 - 웹/모바일 SIDE
	> 관리자가 TBM_01.vue 화면에서 교육자료를 등록 (이미지, 동영상, 외부링크)
		: 모바일에는 해당 화면이 없음. 추후 개발될 관리자용 화면에 들어갈 예정
	> TBM_02.vue 화면에서 교육 개설
		: 모바일에는 해당 화면이 없음. 추후 개발될 관리자용 화면에 들어갈 예정
 - 모바일 SIDE
	> 상기 관리자가 등록한 TBM 교육에 사용자 참여
		: MainView 에 "TBM 참석" DIV 수정 필요 
			1) 참석하기 버튼 삭제
		: TBM 참석 옆 ">" 버튼 클릭 시 화면전환
			1) 전환된 화면은 하기 TBM 상세 화면 참고



## TBM 상세 화면
1. 3가지 텝으로 구성 (참석가능, 교육중, 서명패드)
	1. 참석가능 (교육 시작전 화면, 교육중 화면, 교육 완료 화면)
		: 관리자가 만든 TBM 교육에서 교육 시작전 개설 상태인 항목들만 카드 형태로 리스트가 보임
		: TBM 교육 카드에는 교육 개설자명, TBM 교육 제목, 교육 개설 일시가 뜸.
		: 해당 카드를 클릭 시 입실 비밀번호 입력란이 나오며 인증 성공 시 "교육 시작전 화면"으로 이동

		1-1. 교육 시작전 화면
			: "교육 시작전 화면"에선 우측 상단에 새로고침 버튼과, 교육제목, 교육 개설자명, 교육 개설 일시, "교육이 곧 시작됩니다." 라는 메시지와 교육 참석자 리스트, 그리고 하단에 "퇴실하기", "시작하기" 버튼이 보이면 됨
			: 참석자 리스트엔 이름과 입실 시간만 뜨면 됨
			: 나가기 버튼을 누르면 참석가능 탭으로 회귀, 참석 인원에서 빠짐
			: 시작하기 버튼 클릭 시 분기 처리, 만약 관리자가 교육시작 버튼을 눌렀을 경우는 "교육중 화면"으로 이동, 아직 관리자가 교육시작 버튼을 누르지 않은 경우는 "아직 관리자가 교육을 시작하지 않았습니다." 라는 메시지 출력

		1-2. 교육중 화면
			: 교육제목, 교육내용, 교육자료(슬라이드), 연관된 위험성 평가 리스트(해당 리스트 클릭 시 웹에서 Risk_03.vue 화면의 연계 팝업인 "위험성 평가 정보" 팝업에서 보여지는 내용이 정리되어 보여져야 함), 중도퇴실(붉은 계통의 색 버튼), 교육완료(버튼)
			: 교육자료 슬라이드란 교육 콘텐츠는 하나에 최대 3개까지의 교육 자료가 담길 수 있는데 이걸 좌우로 넘겨가며 볼 수 있도록 처리, 만약 등록된 교육자료가 여러개일 경우 교육자료1, 교육자료2 이런식으로 영역을 분리해서 슬라이드 표시
			: 중도퇴실 버튼 클릭 시 "해당 교육 이수를 포기하시겠습니까 ?" 라는 confirm 메시지 후 확인 누르면 "참석가능" 화면으로 회귀
			: 교육완료 버튼 클릭 시 분기처리, 만약 관리자가 교육종료 버튼을 눌렀을 경우는 퇴실 비밀번호 입력란이 나오며 인증 성공 시 서명패드가 뜨고 해당 패드에 서명 완료 시 "정상적으로 교육을 이수했습니다." 라는 메시지와 함께 "참석가능" 화면으로 회귀, 아직 관리자가 교육종료 버튼을 누르지 않은 경우는 "아직 관리자가 교육을 종료하지 않았습니다." 라는 메시지 출력

	2. 교육중
		: 교육이 시작되고 아직 종료되지 않은 TBM 교육들이 카드 형태 리스트로 보임
		: 교육중 카드에는 교육 개설자명, TBM 교육 제목, 교육 개설일시, 교육 시작일시가 뜸.
		: 카드 클릭 시 내가 참여했던 교육에는 입실 비밀번호 입력 후 재참여 가능

	3. 교육완료
		: 내가 참여했던 교육 리스트가 카드형태로 보여야 함 (이수하지 못한 항목도 보여야 함)
		: 교육완료 카드에는 교육개설자명, TBM 교육 제목, 교육 개설일시, 교육시작일시, 교육종료일시, 교육 이수여부가 보여야함
		: 교육완료 카드 클릭 시 교육제목, 교육내용, 교육자료(교육자료명만, 콘텐츠는 안보여도 됨), 연관된 위험성 평가 리스트(위험성 평가 제목만 보여도 됨), 내가한 서명 가 보여야 함
