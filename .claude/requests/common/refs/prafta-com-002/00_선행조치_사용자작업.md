> **A-1(FCM 프로젝트/키) 미확정 시 작업지시서 착수 금지** (전송 자체가 불가능).

> 표기: 🧑‍💻 = YJ가 직접 / 🤖 = Claude(다음 세션)가 처리 / 🧑‍💻+🤖 = 협업.

## A. 필수 선행 (없으면 착수 불가)

### A-1. 🧑‍💻 FCM 프로젝트 + 서비스 계정 키 — **가장 중요**
- [ ] Firebase 프로젝트가 있는가? 없으면 Firebase 콘솔에서 생성.
- [ ] **서비스 계정 키(JSON)** 발급(Firebase 콘솔 → 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성).
- [ ] 이 키를 **어디에 둘지/어떻게 주입할지** 결정(아래 A-2와 연결). **절대 git 커밋 금지**(CLAUDE.md 시크릿 규칙: `google-services.json`/서비스계정 키 커밋·출력 금지).
  - 권장: 파일은 서버 디스크의 비커밋 경로 또는 시크릿 매니저에 두고, **경로/내용을 환경변수로 주입**.
  - 예) `FIREBASE_CREDENTIALS_PATH=/etc/prafta/firebase-sa.json` 또는 `FIREBASE_CREDENTIALS_JSON=<JSON 원문>`.
- [ ] 결정한 환경변수 이름을 작업지시서 §2에 알려주기(또는 기본값 그대로 쓸지).

> 이 항목이 없으면 워커가 FCM 인증을 못 해 전송이 전혀 안 됩니다. **반드시 선행.**

### A-2. 🧑‍💻 키 주입 방식 / .env 등록
- [ ] A-1에서 정한 환경변수를 로컬/운영 실행 환경에 등록(기존 `JWT_SECRET` 등과 같은 자리 — `.env`/IntelliJ env/시스템 환경변수). → `.claude/context/backend-environment.md` 의 env 운영 방식과 동일.
- [ ] `.env.example` 에 키 이름 추가(실값 없이)는 🤖가 작업지시서에서 같이 처리.

### A-3. 🧑‍💻 안드로이드 앱의 디바이스 토큰 등록 여부 확인 — **확인 필요**
- [ ] 앱(Flutter/webview)이 FCM SDK로 디바이스 토큰을 받아 서버 `tb_user_device.PUSH_TOKEN` 에 저장하는 흐름이 **이미 있는가?**
  - DB에 `PUSH_TOKEN` 컬럼은 존재하나(확인됨), **실제로 채워지고 있는지**가 불명확.
  - 없으면: 워커가 보낼 토큰이 없어 전송 대상이 0이 됨 → **앱 측 토큰 등록 작업이 별도 선행**(앱 프로젝트/Flutter 영역, 본 작업지시서 비범위).
- [ ] (Android 우선) `google-services.json` 앱에 통합되어 있는지. iOS(APNs)는 후속.

> A-3가 안 되어 있으면, 워커는 만들어도 "보낼 토큰이 없음"으로 동작만 하고 도달은 안 됩니다.
> 워커 구현 자체는 진행 가능하나, **실제 도달 테스트는 앱 토큰 등록 완료 후** 가능.

## B. 운영 정책 결정 (코드 작성 불가, 사람이 정해야 함)

### B-1. 🧑‍💻 발송 주기 / 활성화
- [ ] 폴링 주기: 권장 기본 = 30초~60초 fixedDelay(또는 cron). 실시간성 요구 vs 부하로 결정.
- [ ] 워커 **기본 비활성 게이트**로 시작(기존 `LeaveGrantScheduler` 패턴: `prafta.push.worker.enabled=false` 기본). 운영 검증 후 켜기. → 켜는 시점만 YJ 결정.

### B-2. 🧑‍💻 재시도 / 실패 정책
- [ ] 최대 재시도 횟수(예: 3회)와 초과 시 FAILED 고정. `tb_noti_outbox.RETRY_CNT`/`ERROR_MSG`/`SEND_STATUS` 활용(컬럼 이미 존재).
- [ ] 무효 토큰(FCM `UNREGISTERED`/`INVALID_ARGUMENT`) 응답 시 해당 `PUSH_TOKEN` 정리 정책: soft-delete 할지/NULL 처리할지/디바이스 행 비활성할지.

### B-3. 🧑‍💻 동시성 / 인스턴스 수
- [ ] 백엔드를 **단일 인스턴스**로 돌릴지(다중이면 워커 중복 발송 방지용 행 잠금 필요). 단일이면 MVP 단순 구현 가능.

### B-4. 🧑‍💻 비용/할당량 인지
- [ ] FCM 무료 한도/요금, 발송량 추정. (대량 발송 시 배치 멀티캐스트 고려 — 작업지시서에 옵션 명시.)
