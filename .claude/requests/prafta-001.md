## 근태 조회용 화면 만들기

백엔드 : com.prafta.web.attd.attd08을 사용해서 신규 화면 개발
프론트 엔드 : views/Attd_08.vue (신규 생성 필요)

1. 조회 조건 : 기간(from, to), 사업장, 소속부서(node), 사용자명

2. 화면상 보여져야 할 항목들
	1. 사용자 관련 정보
	2. 근태 체크 날짜, 스케줄 정보, 실제 근태정보, 정규화 근태 시간, 외근지의 경우 수집된 GPS 정보를 지도에서 볼 수 있는 기능
	3. 지각, 조기퇴근 등의 스케줄대비 근태 상태

3. 사용자가 봤을 때 이해하기 쉬운 구조여야 하며 UI가 깨지지 않아야 함
