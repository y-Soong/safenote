\## AttdDayDetailPop.vue 화면 수정의 건



1. 해당 화면에서 초과근무를 입력할 때 오동작 되고 있는 부분을 수정해줘

\- 초과근무를 여러번 입력하면 같은 시간이여도 계속 데이터가 들어가는 현상을 확인했어

&#x09;초과근무를 2번 만들어 저장한 후 다시 팝업을열어서 화면상에서만 초과근무 데이터를 지운 뒤 다시 신규 초과근무 데이터를 입력하면 값이 들어가져 아래 쿼리를 보면 이해가될거야
EX) SELECT \* 
FROM TB\_USER\_OVERTIME\_MGMT

WHERE ATTD\_ID = '2026051600035'

\-관련해서 초과근무 생성 API 호출 시 TB\_USER\_OVERTIME\_MGMT 테이블에서 ATTD\_ID 기준으로 같은 시간대에 입력된 초과근무 데이터가 있는지를 체크해서 없을 경우만 데이터가 INSERT 돼야 해
