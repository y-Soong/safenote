# 앱 작업지시서 - 모바일 관리자 플로우 (M-11 ~ M-13)

> 본 문서는 TBM 모듈의 **모바일 관리자 화면 3개**를 정의합니다.
> 백엔드 API는 `04_BACKEND_SPEC_APP.md §8~§9` 참조.
> 웹 관리자 화면과 거의 동일한 기능, 다만 모바일 환경 특화.

---

## 0. 본 문서에서 다루는 화면

| 화면 ID | 이름 | 설명 |
|---|---|---|
| M-11 | 모바일 관리자 콘솔 | 웹 W-04~W-08의 모바일 버전 (개설·진행·이력) |
| M-12 | 일용직 QR 스캔 (입실) | 카메라 QR 스캔으로 일용직 입실 |
| M-13 | 일용직 종료 서명 받기 | QR 재스캔 + 일용직 본인 서명 |

---

## 0.1 ⚠️ 웹 화면(W-04~W-15)과의 관계

YJ 결정사항: **"웹에서 가능한 기능은 모두 모바일에서도 가능해야 한다"**

이 원칙에 따라 모바일 관리자 콘솔(M-11)은 **웹 W-04~W-15의 거의 모든 기능을 포함**합니다.

| 웹 화면 | 모바일 매핑 |
|---|---|
| W-04 세션 목록 | M-11 > 세션 목록 탭 |
| W-05 세션 개설 | M-11 > 개설 화면 |
| W-06 세션 상세/수정 | M-11 > 세션 상세 |
| W-07 진행 콘솔 | M-11 > 진행 화면 |
| W-08 입실자 모니터링 | M-11 > 참여자 탭 |
| W-09 일용직 QR 스캔 | **M-12** (분리) |
| W-10 종료 처리 | M-11 > 종료 모달 |
| W-11 강제 종료 | M-11 > 강제 종료 모달 |
| W-12 이력 조회 | M-11 > 이력 탭 |
| W-13 출결 상세 | M-11 > 출결 상세 |
| W-14 미이수 처리 | M-11 > 미이수 모달 |
| W-15 사용자별 이력 | M-11 > 사용자 이력 |
| (콘텐츠 라이브러리 W-01~03) | M-11 > 자료 관리 탭 |

본 문서는 **모바일 환경 특화 사항만 다룸**. 기능 상세는 웹 문서 참조.

## 1. M-11: 모바일 관리자 콘솔

### 1.1 화면 구성 - 메인 탭 구조

```
┌──────────────────────────────────┐
│  TBM 관리                    ⚙   │
├──────────────────────────────────┤
│  [진행중] [세션] [이력] [자료]    │  ← 4탭
├──────────────────────────────────┤
│                                  │
│        선택된 탭 내용              │
│                                  │
└──────────────────────────────────┘
```

### 1.2 4개 탭 구성

#### 탭 1: 진행중 (기본)

현재 IN_PROGRESS 또는 OPENED 상태인 세션 목록.

```
┌──────────────────────────────────┐
│ [진행중] 세션 이력 자료           │
├──────────────────────────────────┤
│  ┌──────────────────────────┐   │
│  │ ▶ 5월 1주차 TBM (진행중)  │   │
│  │ A공장 · 08:05~ (12분 30초)│   │
│  │ 30명 입실 · 2명 이상신호  │   │
│  │            [진행 콘솔 →]   │   │
│  └──────────────────────────┘   │
│                                  │
│  ┌──────────────────────────┐   │
│  │ 📋 신규 TBM (개설됨)      │   │
│  │ A공장 · 비번: 123456      │   │
│  │ 0명 입실                  │   │
│  │            [진행 콘솔 →]   │   │
│  └──────────────────────────┘   │
│                                  │
│  [+ 새 TBM 개설]                  │
└──────────────────────────────────┘
```

#### 탭 2: 세션 (전체 목록)

W-04 모바일 버전. 필터·검색·페이징.

#### 탭 3: 이력

W-12 모바일 버전. 종료된 세션 위주.

#### 탭 4: 자료

W-01 콘텐츠 라이브러리 모바일 버전.

### 1.3 모바일 특화 사항

| 항목 | 웹 | 모바일 |
|---|---|---|
| 화면 구성 | 다중 패널 | 단일 패널 + 탭 |
| 필터 UI | 상단 필터 바 | 풀스크린 필터 모달 |
| 그리드 | 테이블 (다중 컬럼) | 카드 리스트 (요약 정보만) |
| 페이지 크기 | 20 | 10 |
| 액션 | 인라인 버튼 | 행 클릭 또는 스와이프 |
| 비번 표시 | 큰 폰트 표시 | **더 큰 폰트** (구두 전달 용이) |

### 1.4 TBM 진행 콘솔 (모바일)

웹 W-07의 모바일 버전:

```
┌──────────────────────────────────┐
│  ← 5월 1주차 TBM   [IN_PROGRESS] │
├──────────────────────────────────┤
│  시작 08:05 · 경과 12분 30초     │
│  비번: 입실 123456 / 종료 654321 │
│       [📋 복사]                  │
├──────────────────────────────────┤
│  [현재 슬라이드]                  │
│  ┌──────────────────────────┐   │
│  │  지게차 안전 영상           │   │
│  │  [▶ 재생]                  │   │
│  └──────────────────────────┘   │
│  [⏮] 슬라이드 1/5 [⏭]            │
├──────────────────────────────────┤
│  참여자 (30명)        [QR 스캔]  │
│  ✓ 홍길동                        │
│  ✓ 김철수 ⚠️                    │
│  ✓ 김일용 [QR]                   │
│  ...                             │
├──────────────────────────────────┤
│           [⏹ 교육 종료]          │
└──────────────────────────────────┘
```

### 1.5 모바일 진행 콘솔 특화

| 항목 | 처리 |
|---|---|
| 슬라이드 제어 | 큰 버튼 + 스와이프 제스처 |
| 참여자 명단 | 스크롤 영역, 검색·필터 모달 |
| QR 스캔 | "QR 스캔" 버튼 → M-12 직접 진입 |
| 풀스크린 | 영상 풀스크린 자동 가로 모드 |
| 화면 끄기 방지 | Wake Lock 활성 |

### 1.6 데이터 바인딩

웹 API와 동일 (`04_BACKEND_SPEC_APP.md §8.1 매핑 표`):
- 세션 목록: `GET /api/app/tbm/manager/sessions`
- 세션 상세: `GET /api/app/tbm/manager/sessions/{no}`
- 슬라이드 제어: `POST /api/app/tbm/manager/sessions/{no}/sync-state`
- 참여자 명단: `GET /api/app/tbm/manager/sessions/{no}/attendances/live`
- 교육 종료: `POST /api/app/tbm/manager/sessions/{no}/end`
- 등등

### 1.7 SSE 구독 (관리자용)

```
GET /api/app/tbm/manager/sessions/{no}/sse
```

이벤트:
- `attendance.updated` → 참여자 명단 갱신
- `session.state` → 현재 슬라이드 자동 동기화 (자기 액션 반영)

### 1.8 권한

- safe, master, 회사별 커스텀 권한
- 999999 사용자는 접근 차단

### 2.5 QR 스캔 라이브러리

| 환경 | 권장 라이브러리 |
|---|---|
| Flutter 네이티브 | `mobile_scanner` 또는 `qr_code_scanner` |
| Vue WebApp (WebView) | `html5-qrcode` |

⚠️ Flutter ↔ WebApp 통신: 어디서 QR 스캔할지 결정.
- **권장: Flutter 네이티브에서 스캔 후 결과만 WebView로 전달** (성능·안정성 우수)
- 또는 WebView에서 직접 (카메라 권한 처리 복잡)

### 2.6 카메라 권한 처리

```
[화면 진입]
  ↓
카메라 권한 확인
  ↓
┌────────────────┬────────────────┐
│ 권한 있음       │ 권한 없음        │
└────────────────┴────────────────┘
  ↓                ↓
카메라 시작       권한 요청
                  ↓
                ┌────────┬────────┐
                │ 허용    │ 거부     │
                └────────┴────────┘
                  ↓        ↓
                카메라     "수동 입력
                시작      만 가능"
                          안내 + 폴백
```

### 2.7 수동 입력 폴백

QR 인식 불가 또는 카메라 사용 불가 시:
- 수동 입력 화면 (QR 토큰 직접 입력)
- 일용직이 QR을 분실/훼손 시 사용
- 보안 우려 시 비활성 가능

### 2.8 연속 스캔 모드

여러 일용직을 빠르게 등록:
- 입실 처리 후 자동으로 다음 QR 스캔 화면 복귀
- "완료" 버튼으로 명시적 종료
- 진행 콘솔로 복귀

### 2.9 음성/진동 피드백

- QR 인식 성공: 짧은 비프음 + 진동
- 입실 처리 성공: 다른 비프음 + 긴 진동
- 에러: 경고음

### 2.10 데이터 바인딩

**미리보기 (선택):** `POST /api/app/tbm/qr/preview` (`04_BACKEND_SPEC_APP.md §9.1`)

```json
{ "qrToken": "abc123..." }
```

응답:
```json
{
    "dailyUserNo": 5001,
    "userNm": "김일용",
    "phoneLast4": "1234",
    "expireDt": "2026-06-30",
    "isFixed": false,
    "isExpired": false
}
```

**입실 처리:** `POST /api/app/tbm/sessions/{no}/qr-attendance/enter` (`§9.2`)

```json
{
    "qrToken": "abc123...",
    "managerGpsLat": 37.5665,
    "managerGpsLng": 126.9780
}
```

### 2.11 에러 처리

| 에러 | 메시지 | 행동 |
|---|---|---|
| QR 형식 오류 | "올바른 QR 코드가 아닙니다" | 재시도 |
| 만료 | "만료된 QR 코드입니다" | 안내 후 닫기 |
| 중복 입실 | "이미 입실한 일용직입니다" | 안내 후 닫기 |
| 상태 위반 | "교육이 시작되어 입실 불가" | 안내 후 닫기 |
| 네트워크 | "네트워크 오류 - 다시 시도해주세요" | 재시도 |

## 3. M-13: 일용직 종료 서명 받기

### 3.1 진입 경로

- M-11 진행 콘솔 또는 종료 시점에 "일용직 QR 종료" 액션
- 또는 참여자 명단에서 일용직 행 클릭 → "종료 처리"

### 3.2 화면 구성 - 1단계: QR 재스캔

M-12와 동일한 카메라 화면. 차이점:
- 화면 제목: "일용직 종료 QR 스캔"
- 상단 안내: "일용직이 가진 QR을 다시 스캔하세요"

### 3.3 화면 구성 - 2단계: 정보 확인 + 서명 안내

```
┌──────────────────────────────────┐
│  ← 김일용 - 교육 종료              │
├──────────────────────────────────┤
│                                  │
│  ✓ 김일용 확인됨                  │
│  입실: 08:03                      │
│                                  │
│  📱 본인에게 폰을 건네서           │
│     서명을 받아주세요              │
│                                  │
│         [서명 받기 시작 →]        │
│                                  │
└──────────────────────────────────┘
```

### 3.4 화면 구성 - 3단계: 일용직 서명

```
┌──────────────────────────────────┐
│  김일용 님, 서명해주세요           │
├──────────────────────────────────┤
│                                  │
│  ┌──────────────────────────┐   │
│  │                          │   │
│  │                          │   │
│  │     [서명 캔버스]          │   │
│  │     (가로 모드 권장)        │   │
│  │                          │   │
│  │                          │   │
│  └──────────────────────────┘   │
│                                  │
│  [지우기]            [완료]      │
│                                  │
│  ⓘ 폰을 다시 관리자에게 돌려주세요 │
└──────────────────────────────────┘
```

### 3.5 서명 캔버스

M-08과 동일한 컴포넌트 재사용 가능.

**차이점:**
- 화면 안내 메시지가 일용직 본인 대상
- 다국어 지원 시 일용직 모국어로 (Phase 2)
- 가로 모드 자동 전환 (서명 공간 넓힘)

### 3.6 서명 후 동작

```
[서명 완료]
  ↓
PNG 변환 + multipart 구성
  ↓
POST /api/app/tbm/sessions/{no}/qr-attendance/{ano}/exit
  - qrToken: 재스캔으로 검증
  - signatureFile: PNG
  ↓
응답:
  - 200 → "종료 처리되었습니다" 토스트
  - 다음 일용직 QR 스캔 화면으로 (연속 모드)
  - 또는 M-11 복귀
```

### 3.7 데이터 바인딩

**호출:** `POST /api/app/tbm/sessions/{no}/qr-attendance/{attendanceNo}/exit` (`04_BACKEND_SPEC_APP.md §9.3`)

multipart/form-data:
```
qrToken: "abc123..."
signatureFile: <binary PNG>
```

### 3.8 일용직 서명 정책

- **빈 서명 차단**: 캔버스에 흔적 없으면 "완료" 비활성
- **재서명 가능**: "지우기"로 재시도
- **외국인 노동자**: 한자 또는 모국어 서명도 인정 (필체 식별보다 본인 의사 표시가 중요)

## 4. 모바일 특화 운영 가이드 (영업/온보딩용)

본 가이드는 작업지시서이지만, **운영 가이드를 영업 자료에 포함할 가치**가 있어 명시:

### 4.1 일용직 TBM 운영 절차

**관리자 매뉴얼:**

1. **교육 시작 전**
   - 일용직 명단 확인 (QR 종이 지참 여부)
   - 작업장 또는 공터에 모두 모임
   - 관리자가 폰으로 TBM 개설 (M-11 또는 W-05)

2. **일용직 입실**
   - 관리자가 한 명씩 호명
   - 일용직이 QR 종이 제시
   - 관리자가 폰 카메라로 QR 스캔 (M-12)
   - 화면에 표시되는 이름·휴대폰 끝자리 본인 확인
   - 입실 처리

3. **교육 진행**
   - 관리자가 슬라이드 제어 (M-11)
   - 모든 참여자가 동시에 같은 화면 시청
   - 영상은 관리자 폰 스피커로 공동 청취 (or 외부 스피커 연결)

4. **교육 종료**
   - 정규직은 본인 폰에서 비번 입력 + 서명
   - 일용직은 관리자가 QR 재스캔
   - 관리자가 폰을 일용직에게 건네서 서명 받기 (M-13)
   - 모든 일용직 처리 후 세션 종료

### 4.2 모바일 + 웹 병용 케이스

- **회의실 + 빔프로젝터 환경**: 웹(노트북·태블릿)으로 진행
- **현장 + 라인 옆**: 모바일로 진행
- **둘 다 가능**: 데이터는 실시간 동기화 (SSE)

### 6.2 WebView ↔ Flutter 통신 (참고)

```dart
// Flutter 측
final controller = WebViewController()
  ..addJavaScriptChannel('PraftaBridge', onMessageReceived: (msg) {
    final data = jsonDecode(msg.message);
    switch (data['action']) {
      case 'startQrScan':
        _startQrScan().then((qrToken) {
          controller.runJavaScript('window.onQrScanned("$qrToken")');
        });
        break;
      case 'getGpsPosition':
        // ...
        break;
    }
  });
```

```javascript
// WebApp 측
function scanQr() {
  return new Promise((resolve) => {
    window.onQrScanned = (qrToken) => resolve(qrToken);
    window.PraftaBridge.postMessage(JSON.stringify({ action: 'startQrScan' }));
  });
}
```

⚠️ 실제 통신 프로토콜은 기존 Prafta WebApp 컨벤션 확인 (Claude Code 로컬).
