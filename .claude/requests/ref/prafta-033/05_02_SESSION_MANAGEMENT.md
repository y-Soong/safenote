### 1.2 컴포넌트 구성

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 헤더 | 타이틀 + "TBM 개설" 버튼 | safe + 회사별 커스텀 권한만 |
| 필터 | 사업장 / 상태 / 기간 / 개설자 / 검색어 | URL 쿼리 동기화 |
| 그리드 | 정렬·페이지네이션 가능 | 행 클릭 시 W-06 이동 |
| 액션 컬럼 | 상태별 가변 | 다음 표 참조 |

### 1.3 상태별 액션 표시

| STATUS_CD | 표시 | 가능 액션 |
|---|---|---|
| DRAFT | 회색 배지 | 수정(✏️), 삭제(🗑) |
| OPENED | 파란 배지 | 진행(▶), 수정(✏️), 취소(🗑) |
| IN_PROGRESS | 초록 배지 (펄스 애니메이션) | 진행 화면 이동(▶), 강제 종료(W-11) |
| COMPLETED | 회색 배지 | 이력 보기(📋) |
| CANCELLED | 빨간 배지 | 보기만 |

### 1.4 컬럼 정의

| 컬럼 | 표시 데이터 | 정렬 |
|---|---|---|
| NO | 세션 번호 | 가능 |
| 제목 | session.title | 가능 |
| 사업장 | site_nm (이름 표시) | 가능 |
| 상태 | session.statusCd (배지) | 가능 (우선순위: 진행중 > 개설 > DRAFT > 완료) |
| 개설일 | session.insertDate (날짜만) | 가능 |
| 참여/완료 | `{attendanceCount} / {completedCount}` | - |
| 액션 | 상태별 버튼 | - |

**위험성평가 연계 표시 (보조 정보):**
- 행 우측 또는 제목 옆에 작은 아이콘으로 `🔗 2건` (위험성평가 연계 수)
- 호버 시 위험성평가 제목 툴팁
- **0건이면 ⚠️ 경고 색상** (위험성평가 미연계 — Prafta 영업 메시지 강화)

### 1.5 데이터 바인딩

**호출:** `GET /api/web/tbm/sessions` (참조: `03_BACKEND_SPEC_WEB.md §5.1`)

### 1.6 사용성

- **실시간 갱신**: IN_PROGRESS 세션이 있으면 30초마다 자동 갱신 (참여/완료 카운트)
- **즐겨찾기/고정**: (Phase 2) 자주 보는 세션 고정
- **빠른 개설**: 과거 세션 우측에 "동일하게 개설" 버튼 → W-05에 데이터 prefill
- **CSV/Excel 내보내기**: (선택) 이력 외부 보고용

### 2.2 필드 정의

#### 기본 정보

| 필드 | 타입 | 필수 | 검증 |
|---|---|---|---|
| 사업장 | 셀렉트 | Y | 자기 회사 사업장 |
| 제목 | 텍스트 | Y | 최대 200자 |

#### 교육 내용 (리치 텍스트 에디터)

- **라이브러리**: Tiptap (권장) 또는 기존 Prafta 에디터
- **출력 형식**: HTML (`CONTENT_FORMAT_CD = 'RICH_HTML'`)
- **지원 기능 (MVP)**: 굵게, 기울임, 밑줄, 순서/순서 없는 목록, 링크, 줄바꿈, 헤딩 3단계까지
- **불필요 기능 제거**: 이미지 삽입 (별도 첨부자료 영역으로), 색상 변경, 폰트 변경
- **필수 검증**: HTML 태그 제거 후 텍스트 길이 ≥ 10자 (빈 `<p></p>` 거부)
- **글자 수 표시**: 우측 하단 "100 / 5000자"

#### 첨부 자료 (W-01 콘텐츠 라이브러리에서 선택)

- "+ 라이브러리" 버튼 클릭 → 콘텐츠 선택 모달 (W-01의 압축 버전)
- **다중 선택 허용**
- 추가된 항목:
  - **드래그 앤 드롭으로 순서 변경**
  - 우측 "✏️ 세션 설명" 버튼 → `OVERRIDE_DESCRIPTION` 입력 (이 세션에서만 다른 설명 적용)
  - 우측 "🗑 제거" 버튼 → 세션에서 제거 (콘텐츠 자체는 보존)
- 표시 정보: 제목, 카테고리 배지, 항목 수

⚠️ 방향 A(묶음 모델) 기준: 1개 행 = 1개 묶음 = 여러 세부항목 자동 포함.

#### 위험성평가 연결 (옵션)

- "+ 추가" 버튼 → 위험성평가 선택 모달
- **이 모달은 기존 위험성평가 모듈의 검색·선택 UI 재사용**
- **다중 선택 허용**
- 위험성평가 표시 정보: 제목, 상태 (조치완료/임시조치/요청 등)
- **0건일 때 경고 메시지 자동 표시**:
  > ⚠️ 위험성평가가 연결되지 않았습니다. 사고 발생 시 설득력이 떨어질 수 있습니다.

  (배경 색: amber 50, 텍스트: amber 800)
- 0건이어도 개설 가능 (옵션). 추후 사고관리 출시 시 문구 강화.

#### GPS 설정

- **검증 모드 라디오**:
  - 자동 (AUTO) — 페이지 로드 시 GPS 자동 수집, 성공 시 위도/경도 표시
  - 수동 확인 (MANUAL) — GPS 미수집, 관리자가 명시적 체크박스 확인 ("모든 참여 예정자가 교육 장소에 있음")
  - 비활성 (DISABLED) — GPS 검증 안 함, 비번만 사용
- **반경**: 숫자 입력, 50~1000m 범위 (기본 100m)
- **GPS 수신 상태 표시**:
  - 성공: "📍 37.5665, 126.9780 (수집됨)"
  - 실패: "⚠️ GPS 수신 불가 — 수동 확인 모드로 전환됨"
  - 권한 거부: "🚫 위치 권한이 거부됨 — 비활성 모드로 전환"
- 페이지 로드 시 `navigator.geolocation.getCurrentPosition` 자동 호출

### 2.3 GPS 처리 흐름

```
페이지 로드
  ↓
navigator.geolocation 호출
  ↓
┌────────────────┬────────────────┬────────────────┐
│ 성공            │ 실패 (timeout)  │ 권한 거부        │
└────────────────┴────────────────┴────────────────┘
  ↓                ↓                ↓
모드: AUTO       안내 모달 표시:    안내 메시지:
좌표 저장         "GPS 수신 불가.    "위치 권한 허용 후"
                  수동 확인하시       또는 비활성 진행"
                  겠습니까?"
                  ↓
                체크박스 + 확인
                  ↓
                모드: MANUAL
                gpsManualConfirmYn='Y'
```

### 2.4 저장 동작

**버튼 분리:**
- **임시 저장**: STATUS_CD = 'DRAFT'로 저장 (개설 안 함)
- **개설하기**: STATUS_CD = 'OPENED'로 저장 (입실 가능 상태)

**임시 저장 vs 개설 차이:**
- 임시 저장: 비번 생성 X, 입실 불가
- 개설: 비번 자동 생성 (서버 측), 즉시 입실 가능

**검증 (개설 시):**
- 제목, 교육 내용 (10자 이상), 사업장 필수
- 첨부자료 최소 1개 (선택 사항? 결정 필요)
- 위험성평가 0건이어도 OK (단 경고 메시지 노출됨)
- GPS 모드 = MANUAL 시 확인 체크박스 필수

**저장 후 동작:**
- 임시 저장 성공 → "임시 저장되었습니다" 토스트 + W-04 이동
- 개설 성공 → 즉시 W-07 (TBM 진행 콘솔)로 이동 (자동 또는 확인 후)

### 2.5 데이터 바인딩

**호출:** `POST /api/web/tbm/sessions` (참조: `03_BACKEND_SPEC_WEB.md §5.3`)

**요청 본문 구성 (개설 시):**

### 2.6 사용성 요구사항

- **자동 저장**: 30초마다 자동 임시 저장 (Phase 2)
- **이탈 경고**: 작성 중 페이지 이탈 시 확인 다이얼로그
- **콘텐츠 미리보기**: 첨부 자료 클릭 시 모달로 미리보기

## 3. W-06: TBM 세션 상세/수정

### 3.1 화면 구성 (상태별 가변)

#### DRAFT / OPENED 상태 (수정 가능)

W-05와 유사하지만 다음 추가:
- 상단에 상태 배지 + "수정" 모드 안내
- 개설 시각 표시
- **입실/종료 비번 표시 영역** (OPENED 상태만)
- **"비번 재발급"** 버튼 (선택)
- **"교육 시작"** 버튼 (OPENED만, 큰 강조 버튼)

```
┌─────────────────────────────────────────────────────────────┐
│  TBM 세션 - 5월 1주차 TBM             [OPENED]   [닫기]    │
├─────────────────────────────────────────────────────────────┤
│  개설 시각: 5/1 07:30                                        │
│                                                              │
│  📌 비밀번호 (관리자에게만 표시)                              │
│  입실 비번: 123456 [📋 복사]                                │
│  종료 비번: 654321 [📋 복사]      [🔄 재발급]               │
│                                                              │
│  [기본 정보·교육 내용·첨부 자료·위험성평가·GPS - W-05와 동일]│
│                                                              │
│       [수정 저장]  [취소]  [▶ 교육 시작]                    │
└─────────────────────────────────────────────────────────────┘
```

#### IN_PROGRESS / COMPLETED / CANCELLED 상태 (조회만)

- 모든 필드 readonly
- 비번은 IN_PROGRESS만 표시 (COMPLETED에선 숨김)
- 상태별 추가 정보:
  - IN_PROGRESS: 시작 시각, 참여자 수, "진행 콘솔 보기" 버튼 (W-07 이동)
  - COMPLETED: 시작/종료 시각, 참여자 수, "이력 상세" 버튼 (W-13 이동)
  - CANCELLED: 취소 시각, 취소 사유

### 3.2 액션 버튼 (상태별)

| 상태 | 가능 액션 |
|---|---|
| DRAFT | 수정 저장 / 개설 / 삭제 / 취소 |
| OPENED | 수정 저장 / 비번 재발급 / 교육 시작 / 세션 취소 |
| IN_PROGRESS | 진행 콘솔 이동 / 강제 종료 (W-11) |
| COMPLETED | 이력 상세 이동 / 출결 조회 |
| CANCELLED | 보기만 |

### 3.3 비번 재발급 동작

- 클릭 시 확인 다이얼로그: "기존 비번을 무효화하고 새 비번을 발급합니다. 진행하시겠습니까?"
- 확인 시 `POST /api/web/tbm/sessions/{no}/regenerate-passwords` 호출
- 응답으로 새 비번 표시
- **재발급 사유 입력**은 옵션 (Phase 2)

### 3.4 교육 시작 동작

- 클릭 시 확인 다이얼로그: "교육을 시작하면 신규 입실이 차단됩니다. 시작하시겠습니까?"
- 확인 시 `POST /api/web/tbm/sessions/{no}/start` 호출
- 성공 시 자동으로 W-07 (TBM 진행 콘솔)로 이동
- SSE로 입실 대기 중인 모든 근로자에게 `session.started` 알림 (백엔드 처리)

### 3.5 데이터 바인딩

**조회:** `GET /api/web/tbm/sessions/{eduSessionNo}` (참조: `03_BACKEND_SPEC_WEB.md §5.2`)
**수정:** `PUT /api/web/tbm/sessions/{eduSessionNo}` (참조: `03_BACKEND_SPEC_WEB.md §5.4`)
**취소:** `POST /api/web/tbm/sessions/{eduSessionNo}/cancel`

## 6. Claude Code 작업 시 우선 확인 사항

1. **기존 Tiptap 또는 리치 텍스트 에디터 사용 여부** — 라이브러리, 설정 컨벤션
2. **위험성평가 모듈의 검색·선택 컴포넌트** — 재사용 가능한 모달이 있는지
3. **드래그 앤 드롭 라이브러리** — vuedraggable, SortableJS 등 기존 사용 중인 것
4. **사업장 셀렉트 컴포넌트** — 자기 회사 사업장 목록 로드 컨벤션
5. **GPS 수집 유틸** — `navigator.geolocation` 래퍼가 이미 있는지
6. **사용자 권한 체크 컴포저블** — 화면/버튼 권한 분기 패턴
7. **임시 저장(DRAFT) 정책** — Prafta 다른 모듈에서 DRAFT 패턴 사용 여부

위 사항 확인 후 차이가 있으면 사용자와 협의.
