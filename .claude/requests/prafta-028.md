\## Attd\_07.vue, AttdDayDetailPop.vue, Attd\_05.vue 화면 수정 요청의 건



\# Attd\_07.vue 화면에서 월별로 근태 마감 시에 대한 처리내용.

1. Attd\_07.vue 화면에서 근태가 마감되어 있을 경우 테이블의 각 cell의 bg가 회색 계통으로 잡혀서 관리자로 하여금 해당 월의 근태가 마감 되어 있음을 인지할 수 있도록해야함
2. 근태가 마감되어 있는 경우여도 Attd\_07.vue 화면에서 cell을 더블클릭하면 AttdDayDetailPop.vue 팝업이 떠야함.
3. 근태가 마감되어 있는 경우 AttdDayDetailPop.vue 팝업에서 관리자의 근태 생성/근태 수정/ 근태 삭제/초과근무 생성/ 초과근무 수정/초과근무 삭제 등의 데이터 INSERT / UPDATE 기능이 모두 막혀야 함.
4. Attd\_07.vue 화면에서 근태가 마감된 월의 경우 Attd\_05.vue 화면에서도 근무타입 변경이 막혀야 함(백앤드, 프론트앤드 모두 해당 로직이 있어야 함)



\# 근태 마감 로직으로 근태관련 요청이 있는경우 마감이 안되도록 잡아놨으니 이부분은 참고해서 수정작업 해줘
