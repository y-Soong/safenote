\##  USER\_04 화면 수정 요청의건



1. 조회 조건에 "검색" 버튼 삭제

   1. 공통버튼으로 사용하는 조회 버튼과 중복되는 기능으로 보임
2. 내 위 직급 순 자동 구성 기능 삭제

   1. 화면 성격상 필요없는 기능
3. 조회 조건에 조건 추가

   1. 사업장, 소속부서 추가 요청 (타화면 참고해서 \[코드값] \[버튼] \[코드명값] 구조로 조건넣고 백앤드도 함께 맞춰서 수정)
   2. 결재자명 > 사용자명 변경 요청
4. 결재자 후보(동일 사업장) 수정 

   1. 결재자 후보 (동일 사업장) > 사용자 리스트 변경 요청
   2. 리스트의 사용자명 옆에 사용자명(사용자ID) 형태로 추가 데이터 표시
5. 구조 변경 요청

   1. 프리셋을 여러개 만들 수 있는 구조로 변경 요청
   2. 프리셋 별로 이름을 입력할 수 있도록 변경 요청
   3. 기본 프리셋을 지정할 수 있도록 변경 요청



\## 추가 설명이 필요하거나 모호한 부분이 있을 경우는 채팅으로 질문해줘
