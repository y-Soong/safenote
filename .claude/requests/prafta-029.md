\## 위 케이스는 연차 부여정책은 고정으로 하고 사용자 입사일 조정쪽의 데이터를 바꾸는 방식의 테스트인데 반대로 입사일 조정쪽의 입사일과 처리방식은 고정된 상태로 연차 부여적책이 변경될 때 정상적으로 연차값이 부여되는지에 대한 케이스도 검증해야됨

\## 입사일 조정의 입사일 수정과 처리방식을 고정한 채 연차 부여정책이 바뀔때에 대한 케이스도 위와같이 정리해줘

\## 각 표의 결과에 사용자에게 부여될 연차 개수를 기입해줘

\## 마지막으로 연차부여 정책과 입사일 + 처리방식을 변경에 따른 모든 케이스를 따져서 정상적으로 연차부여 엔진이 동작하는지 체크해줘

&#x09;: EX) 기존 : (연차 부여 정책)입사일 기준 - 월차만 부여, (입사일 수정)입사일 과거로 변경 > 기존 부여 유지 + 누락분만 소급 부여

&#x09;: EX) 변경 : (연차 부여 정책)회연도 기준 - 월차만 부여, (입사일 수정)입사일 미래로 변경 > 기존 부여 유지 + 신규 부여만 변경된 입사일로 계산
