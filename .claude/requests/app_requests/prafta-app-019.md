# 앱 보완 요청 사항


1. 모바일 APP
	1. 초과근무 요청 시 근태시간 체크 안됨
		Ex) 00:00 ~ 07:00, 13:00 ~ 18:00 스케줄인 상태에서 22:38에 1구간, 2구간 근태를 모두 등록 후 22:38 ~ 22:59분 까지 초과근무 생성요청이 가능함
	2. 연차신청
		1. 신청 시간의 시작 시간이 시간:분 으로 입력되게 끔 되어있는데 1분단위로 값을 변경할 수 있도록 되어있는데 이걸 30분 단위로 변경해야 함
		2. 종료 시간을 입력하게 끔 되어있는데 시작시간을 기준으로 +, - 버튼이 있고 버튼을 누를 때마다 시작 시간을 기준으로 사용 단위만큼 종료 시간을 잡아주는 방식으로 변경 요청
	3. 연차 신청, 초과근무 신청, 근태 보정 요청, 스케줄 수정 요청 등
		1. 만들어진 팝업에 사유를 넣지 않으면 저장 버튼이 활성화 안되는 경우가 있는데 전수조사해서 저장 버튼은 기본 활성화로 해놓고 사유가 입력 안될경우 alert창을 띄워서 사유 입력을 요청하는 방식으로 수정 요청
