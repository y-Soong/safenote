설계 메모
화면 구성
1. 마이페이지 메인 — 프로필 카드 + 메뉴 리스트 2개 그룹(계정 / 결재). 메뉴 아래 로그아웃 풀폭 secondary 버튼 + 회원 탈퇴 텍스트 링크(tertiary 톤, 작게). 카카오·토스·네이버 등 대부분의 한국 앱이 채택하는 패턴 — 로그아웃은 잦은 액션이라 한 번에 누르고, 회원 탈퇴는 빈도가 매우 낮으면서 파괴적인 액션이라 시각 비중을 의도적으로 줄여둠.
2. 개인정보 수정 — 풀스크린. 3개 그룹으로 분리: 소속 정보(아이디·사업장·부서·입사일)는 읽기 전용 회색 톤, 기본 정보(이름·성별·생년월일) + 연락처(휴대폰·이메일)는 수정 가능. 휴대폰 변경 시 인증요청 → 인증번호 확인 흐름.
3. 비밀번호 변경 — 풀스크린. 3필드(현재/새/확인) + 규칙 가이드 카드. 새 비밀번호는 입력 즉시 규칙 충족 여부 표기. 푸터 [변경하기]는 미충족 시 disabled.
4. 연차 결재선 관리 — 풀스크린. 작업지시서 v1.1 §3.4.19의 "후속 작업 프리셋 관리 화면"이 본 화면. 기본 프리셋 1개 + 추가 N개를 카드 리스트로 표시.
5. 프리셋 편집 — 풀스크린. 이름 입력 + 기본 토글 + 결재자 리스트(순서 변경 ⬆⬇ / 삭제). 헤더 우측 휴지통 = 프리셋 자체 삭제. 결재자 추가 = 바텀시트.
6. 결재자 검색 바텀시트 — 작업지시서 §3.4.14.2 5-2/5-3 케이스와 동일 패턴 재사용.
7. 로그아웃 확인 모달 — Primary 톤. 타이틀 한 줄만, 부가 설명 없음.
8. 회원 탈퇴 확인 모달 — Danger 아이콘 + 사용자 이름 호명("김여진님, 탈퇴 전 꼭 확인해주세요") + 본문 한 줄 + 회색 콜아웃(법령 보존 안내·재가입 시 미연계 안내) + 확인 체크박스 + [탈퇴하기]. 체크박스 미체크 시 [탈퇴하기] disabled — 가이드 §5.7 "추가 게이트" 패턴.
결정 사항
· "마이"는 하단 탭바 5번째 탭으로 추가, 헤더 타이틀은 "마이페이지"로 표기 (탭바 라벨은 공간 제약으로 "마이" 유지).
· 로그아웃·회원 탈퇴는 메뉴 리스트에서 분리. 한국 모바일 앱의 보편적 패턴인 하단 풀폭 secondary 버튼 + 텍스트 링크 조합 채택. "기타" 같은 의미 약한 그룹 라벨을 생성하지 않음.
· 회원 탈퇴 시 데이터 처리 정책: 출퇴근·근태 기록은 법령에 따라 3년 보존 / 신청 중 연차는 자동 취소 / 결재선 프리셋은 즉시 삭제 / 재가입 시 기존 기록과 미연계.
· 이름 변경 정책: 별도 인증 없이 변경 가능, 변경 빈도 제한 없음. 근태·안전 기록의 키는 USER_CD이므로 변경 시점 이후부터 새 이름이 표시되고 과거 기록은 USER_CD로 자동 연결.
· 알림 아이콘은 메인 헤더에만 노출. 서브 화면은 백 버튼 + 타이틀(가이드 §4.1.2).
· 결재선 프리셋 화면은 작업지시서 v1.1 §3.4.19의 후속 작업 진입점을 마이페이지 하위로 확정.
