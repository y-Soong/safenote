## 모바일 앱 근태 조회 연계 회면 수정 요청

1. MainView에서 "근태 조회" 버튼으로 넘어가는 내 근태 화면에 대한 수정 요청
	1. 오늘 탭
		1. "수정 요청" 버튼을 눌렀을 때 "이번주" 탭에서 날짜별 클릭 이벤트와 동일하게 "스케줄 수정 요청", "근태 보정 요청", "초과근무 신청", "연차 신청"을 고를 수 있는 슬라이드가 떠야 함
	2. 이번달 탭
		1. "수정 요청" 버튼을 눌렀을 때 "이번주" 탭에서 날짜별 클릭 이벤트와 동일하게 "스케줄 수정 요청", "근태 보정 요청", "초과근무 신청", "연차 신청"을 고를 수 있는 슬라이드가 떠야 함
	3. 공통
		1. 스케줄 수정 요청 : 지금은 과거 날짜는 수정 버튼클릭이 막혀있는데 과거 현재 미래가 모두 버튼 클릭이 가능하도록 수정 요청
		2. 근태 보정 요청 : 미래 날짜만 막고 과거 현재는 가능하도록 수정 요청
		3. 초과근무 신청 : 미래 날짜만 막고 과거 현재는 가능하도록 수정 요청(단 근태 데이터가 존재할 때)
		4. 연차 신청 : 미래, 현재, 과거 모두 가능하도록 수정 요청(단 근태 데이터가 존재한다면 연차 신청 불가)
