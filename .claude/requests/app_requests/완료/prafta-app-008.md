## 5\. 출퇴근 횟수 및 구간 제한

### 5.1 기본 원칙 — 스케줄 구간 기반

사용자의 1일 출근 가능 횟수는 해당 일자의 스케줄 구간 수를 따른다.

|스케줄|최대 출근 가능 횟수|설명|
|-|-|-|
|1구간 스케줄|1회|출근 → 퇴근 1쌍|
|2구간 스케줄|2회|출근 → 퇴근 → 재출근 → 퇴근 2쌍|
|스케줄 없음|제한 없음|단, 전량 추가근무 승인 필수 (7.5절 참조)|

### 5.2 재출근 조건

* 재출근(2번째 출근)은 반드시 이전 퇴근 완료 후에만 가능
* 이전 퇴근 없이 재출근 시도 시 시스템 차단
* 2번째 구간 스케줄 시작 전이어도 첫 구간 퇴근만 되어 있으면 재출근 허용

### 5.3 초과 출근 차단

* 스케줄 구간 수를 초과하는 출근 시도는 시스템이 차단
* 차단 시 사용자에게 "초과근무 상신으로 처리하세요"라는 안내 표시
* 3번째 이상 출근이 필요한 업무는 초과근무 상신으로 기록

→ 초과근무 상신은 9.3절 참조

### 5.4 예외 케이스 처리

|상황|처리|
|-|-|
|스케줄 1구간인데 출근 1회 후 재출근 필요|초과근무 상신|
|스케줄 2구간인데 이미 출근 2회 완료 후 재출근 필요|초과근무 상신|
|퇴근 미등록 상태에서 재출근 시도|차단. 근태 보정 요청으로 해소|
|스케줄 없는 날 출근|허용 + 전량 추가근무 상신 필수|

### 5.5 익일 경계 선행 구간 마감 규칙

1구간 또는 2구간 스케줄이 익일로 넘어가는 야간 교대 패턴에 적용한다.

예시 스케줄: 어제 23:00 \~ 오늘 06:00 (1구간) / 오늘 23:00 \~ 내일 06:00 (2구간)

#### 5.5.1 핵심 원칙

2구간 출근은 선행 1구간의 마감 상태에 따라 분기 처리한다.

|선행 1구간 상태|2구간 출근 시 동작|사용자 안내|
|-|-|-|
|출근 + 퇴근 완료 (마감)|즉시 출근 처리|—|
|출근만 처리, 퇴근 미처리 (미마감)|차단|"이전 1구간 근무가 마감되지 않았습니다. 1구간 퇴근을 먼저 처리해주세요."|
|출근 자체 없음 (스킵)|확인 얼럿 후 진행|"1구간 출근 데이터 없이 2구간 출근하는 게 맞나요?" → 확인 시 출근 처리|

#### 5.5.2 케이스별 동작

* **Case A — 정상 흐름**: 어제 23:00 1구간 출근 → 오늘 06:00 1구간 퇴근 → 오늘 23:00 2구간 출근 시도 → 즉시 처리
* **Case B — 1구간 미마감 (강한 차단)**: 어제 23:00 1구간 출근 → 퇴근 누락 → 오늘 23:00 2구간 출근 시도 → 차단. 사용자는 1구간 퇴근 보정 또는 등록 후 재시도
* **Case C — 1구간 스킵 (소프트 차단)**: 어제 1구간 출근 자체 없음 → 오늘 23:00 2구간 출근 시도 → 확인 얼럿. 사용자가 확인 시 2구간만 단독 출근 처리

#### 5.5.3 Case B / Case C 구분 의도

* B는 시스템이 강제 마감할 수 없는 데이터 결손이므로 명시적 차단
* C는 1구간 미수행이 정상일 수 있는 상황(반차·교대 결번 등)이므로 확인만 받고 통과

#### 5.5.4 1구간 출근 시점 (역방향)

* 1구간은 첫 구간이므로 선행 구간 개념 없음
* 전일 2구간 미마감 발견 시 동일 차단 로직 적용 여부 → **\[정책 확정 필요]**

#### 5.5.5 관련 정책

* §5.2 재출근 조건 — 같은 일자 1구간→2구간 재출근. 본 절은 익일 경계로 확장
* §5.4 예외 케이스 — "퇴근 미등록 상태에서 재출근 시도: 차단"과 정합
* §7.4 오류 / 누락 / 중복 처리 — 미마감 1구간 데이터의 사후 처리는 근태 보정 요청 흐름 그대로

#### 5.5.6 미결 항목 — \[정책 확정 필요]

* 스킵 후 진행으로 생성된 2구간 출근 기록에서 누락된 1구간 데이터 처리 방식 (NULL / 별도 마커 / 근태 마감 시 보정 요구 대상)
* 1구간 출근 시점에 전일 2구간 미마감 발견 시 차단 여부 (5.5.4와 동일 이슈, 방향 반대)
* 얼럿 시점 — 출근 버튼 탭 직후 vs GPS 판정 후
* 확인 후 진행으로 생성되는 2구간 출근 기록의 GPS·근무지 외 태그 처리는 §7.2\~§7.3 기존 규칙 그대로 적용
