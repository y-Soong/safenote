[보는 법]
- "라우트 경로"  = 앱 내부 해시 라우터 path (예: /MyAttendance)
- "컴포넌트 파일" = VS Code 에서 실제로 열리는 .vue 파일 경로 (src/views 기준)
- "화면명(업무)" = 사용자가 부르는 화면 이름 / 메인화면 진입 버튼
- "요청서"       = .claude/requests/app_requests/ 하위 작업 요청서

라우트 정의 출처: src/router/index.js (정적 라우트)
                 + 백엔드 app-menu-lists 기반 동적 라우트(dynamicRoutes.js)

7) 네이밍이 헷갈리는 포인트(요약)
────────────────────────────────────────────────────────────

· 요청서 번호 != 화면 파일명. 한 화면이 여러 요청서에 걸쳐 진화함.
    예) MyAttendanceView.vue = app-002(신규) + app-003(GPS) + app-008(야간/외근)

· 메인 버튼 라벨(업무 용어) != 라우트 이름(영문).
    "근태 조회"  -> /MyAttendance
    "잔여 연차"  -> /MyLeaveSummaryView
    "승인요청"   -> /MyRequests
    "안전점검 시작" -> /ChkLst  (구 "일일 안전점검")
    "위험성 발굴"   -> /Risk_01 (구 "위험성 평가")

· prafta-app-009 / prafta-app-010 = app-007 follow-up(결재선 통합) 요청서 단계.
    아직 plan 분해/구현 전이라 대응 신규 화면 파일 없음(AttdRequestView 확장 예정).

· prafta-036-B1/B2 는 "앱 화면" 작업처럼 보이지만 실제로는 백엔드 패키지 리팩터.
    화면(ChkLst.vue / Risk_01.vue)은 무변경 유지가 원칙.

· prafta-038 = Flutter 셸(safenote) APK 빌드 정비. Vue 화면 무관.
