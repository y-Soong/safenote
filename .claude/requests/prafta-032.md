\## 사용자 입사일 변경에 따른 처리방식 제거

&#x20;

1. 현재 HireDateEditPop에서 입사일 변경 후 처리방식을 고르고 있는데 해당 부분을 제거하고 싶어.

   1. 사유 : 처리방식에 따라서 회사에 유리한 구조 혹은 근로자에게 유리한 구조가 나오는데 고객의 니즈를 모르는 상황이라 고정된 형식에서 자동 계산은 리스크가 너무 크다고 판단.
   2. 처리 요청내용

      1. 현재 처리방식을 고르는 부분은 전면 폐기
      2. 대신 변경할 입사일을 입력할 경우 현재 해당 사용자가 가지고 있는 연차수가 아래에 나오고 현재 보유하고 있는 연차 대비 몇개로 수정할지 관리자가 직접 입력하는 구조

         1. 이때 현재 연차의 수 - 수정할 연차의 수가 현재 해당 사용자가 보유하고 있는 잔여 연차의 수보다 클 경우는 저장 불가 (연차 승인 요청으로 잡힌것들도 카운트)
      3. Attd\_09.vue 화면에서 정책 기준 부여 버튼을 누르면 HireDateEditPop에서 빠진 처리방식 부분은 관련 로직에서 제거한 뒤 연차부여정책 + 입사일 + 경력인정을 기준으로 연차 산정
