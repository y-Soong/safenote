\## LeaveTypeCreatePop.vue 화면 수정에 대한 요청



1. 관리자 부여 타입 > 자동 부여 > 부여 규칙에 부여날짜 추가

   1. TB\_SYST\_VAL\_D 테이블의 SYST\_VAL\_CD ='SYS027' 에 SYST\_VAL\_D\_CD='03'로 부여일지정 컬럼을 추가해놨어 확인해줘
   2. 부여일지정 값을 선택하면 실행지점 n개월 전 1일 이부분대신 날짜를 지정하는 컴포넌트가 나왔으면 좋겠어 (년도는 필요없고 DD-MM만 나오면 돼)
2. 관리자 부여 타입 > 수동 부여 > 부여일수 삭제



\## 추가 설명이 필요하거나 모호한 부분이 있을 경우는 채팅으로 질문해줘
