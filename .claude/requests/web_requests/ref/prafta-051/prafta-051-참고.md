모바일 관리자 TBM 수정

## 수정 배경과 flow
- 현재는 개설 시 비밀번호 및 GPS 체크가 이루어짐에 따라 / 실제 교육하는 관리자와 사용자가 현장에 모이지 않은 단계에서 개설만으로 입실 처리가 가능함
- 이후 교육 시작 시 GPS 체크를 별도로 하지 않음에 따라 부정 사용 우려가 있음

- 따라서 '개설' 시점에는 사업장 / 교육제목 / 교육내용 / GPS 검증 여부 (GPS 수집 하지 않음. 관리자도) / 교육자료 선택 / 위험성평가 선택 만 처리 >> 현재 구현된 '임시저장' 이 이 상태랑 동일해서 '임시저장'을 '개설'로 활용
- '교육준비' 상태를 추가하여 이 때 '입실 비밀번호'가 나오고 'GPS 위치 체크'가 이루어짐 (관리자 기준 사용자들의 반경)
- '교육준비' 이후 15분이 경과하면 자동으로 '교육시작' 처리 됨
  단, 관리자가 15분이 도래하기 전 수동 연장 가능
  15분이 경과하지 않은 시점이라도 관리자는 수동으로 '교육시작' 가능함
  >> 관리자가 교육시작 전 입실한 사용자 리스트와 GPS 위치를 확인할 수 있어야 하며,
        GPS 반경을 많이 벗어난 사용자가 있다면 내보내기 가능함
  >> 교육시작 전 '정규직 중 휴대전화 사용이 불가한 사용자'를 검색해서 관리자 권한으로 입실 처리 가능하도록 해야 함 (내가 처음에 '현장처리'로 별도 빼려 했던 기능인데 TBM 은 하나의 흐름에서 처리되는게 사용자 편의성 관점에서 더 나아보여서 수정할게)
  >> 교육시작 전 '일용직 QR 코드'를 관리자가 찍어서 일용직들도 입실 처리 가능하도록 해야 함
- '교육종료' 시 종료 비밀번호가 발급됨
  종료 이후 관리자는 참가한 사용자 리스트와 GPS 위치를 (교육준비 상태에서 찍었던) 보며 특정 사용자는 '미이수' 처리해 버릴 수 있어야 해

## 비밀번호 발급 관련 상세
- 지금은 개설 할 때부터 입실/종료 비밀번호가 함께 나오는데 '교육준비' 상태에서 입실 비밀번호가 발급되고, '교육종료' 상태가 되어야 종료 비밀번호가 발급되어야 해.
- 각 상태 별 비밀번호는 재발급이 가능하지만, 이전 비밀번호 검증을 통과해서 이미 입실처리 된 사용자에게는 영향이 없어야 해 (교육을 튕기거나 하면 안되고 입실 상태가 유지되어야 함)
