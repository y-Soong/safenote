## 1. W-12: TBM 이력 조회

### 1.1 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  TBM 이력                                  [📥 Excel 다운] │
├─────────────────────────────────────────────────────────────┤
│  [사업장 ▼] [기간: 5/1~5/31] [개설자 ▼] [검색어] [조회]   │
├─────────────────────────────────────────────────────────────┤
│  ┌────┬──────────────┬──────┬──────┬───────┬───────┬─────┐│
│  │ NO │ 제목           │ 사업장│ 종료일│참여/이수│ 미이수│위험성││
│  ├────┼──────────────┼──────┼──────┼───────┼───────┼─────┤│
│  │ 1  │ 5월 1주차 TBM │A공장│ 5/1  │ 30/28 │  2    │ 🔗2 ││
│  │ 2  │ 4월 4주차 TBM │A공장│ 4/29 │ 28/28 │  0    │ 🔗1 ││
│  └────┴──────────────┴──────┴──────┴───────┴───────┴─────┘│
└─────────────────────────────────────────────────────────────┘
```

### 1.2 W-04와의 차이

| 항목 | W-04 (세션 관리) | W-12 (이력) |
|---|---|---|
| 대상 상태 | 전체 (DRAFT~COMPLETED) | **COMPLETED, CANCELLED** 위주 |
| 액션 | 진행/수정/삭제 | 조회·통계 위주 |
| 필터 | 상태 포함 | 기간 위주 |
| 추가 컬럼 | - | 이수율, 위험성평가 연계 |
| 내보내기 | - | **Excel/PDF 다운로드** |

### 1.3 컬럼 정의

| 컬럼 | 표시 |
|---|---|
| NO | 세션 번호 |
| 제목 | session.title |
| 사업장 | site_nm |
| 종료일 | session.endedAt (날짜) |
| 참여/이수 | `{attendanceCount} / {completedCount}` + 이수율 % |
| 미이수 | `notCompletedCount` (있으면 빨간색 강조) |
| 위험성평가 | 연계 건수 + 아이콘 (0건이면 ⚠️) |

### 1.4 통계 영역 (선택, MVP 권장)

상단 또는 하단에 요약 통계:
```
┌──────────────────────────────────────────────────┐
│ 5월 합계: TBM 22회 │ 참여 660명 │ 이수율 96%      │
└──────────────────────────────────────────────────┘
```

### 1.5 데이터 바인딩

**호출:** `GET /api/web/tbm/history/sessions` (`03_BACKEND_SPEC_WEB.md §7.1`)

### 1.6 Excel/PDF 다운로드

- **Excel**: 전체 컬럼 + 참여자 명단 (시트 분리)
- **PDF**: 인쇄용 보고서 형식 (감독관 점검 대비)
- 별도 API: `GET /api/web/tbm/history/sessions/export?format=xlsx`

⚠️ Excel/PDF 생성은 Prafta 기존 라이브러리 활용 (Claude Code 로컬 확인). 일반적으로 Apache POI (Excel) + iText/Flying Saucer (PDF) 또는 SheetJS 클라이언트 측 생성.

### 1.7 행 클릭 동작

- 행 클릭 → W-13 (출결 상세) 이동
- "📋" 아이콘 클릭 → 동일

## 2. W-13: 출결 상세

### 2.1 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  5월 1주차 TBM - 출결 상세              [📥 다운] [닫기]   │
├─────────────────────────────────────────────────────────────┤
│  [세션 정보 요약]                                            │
│  사업장: A공장 │ 개설자: 김안전 │ 시작 08:05 │ 종료 08:15  │
│  교육 내용: 지게차 안전수칙... [전체 보기]                  │
│  위험성평가: 지게차 추돌(완료), 작업장 정리(임시조치)        │

│  [참여자 (30명)]                                             │

│  ├────┼────────┼──────┼─────┼─────┼───────┼──────┼──────┤│
│  │ 1  │ 홍길동  │정규직│08:01│08:15│   -   │  ✓   │  📋  ││
│  │ 2  │ 김철수  │정규직│08:02│08:15│백5회  │  ✓   │  📋  ││
│  │ 3  │ 김일용  │일용직│08:03│08:15│   -   │  ✓   │  📋  ││
│  │ 4  │ 이상한  │정규직│08:05│08:14│GPS이탈│  ✕   │  ✏️  ││
│  └────┴────────┴──────┴─────┴─────┴───────┴──────┴──────┘│
```

### 2.2 세션 정보 요약 영역

- 세션 기본 정보 (사업장, 개설자, 시간)
- 교육 내용 요약 (앞 100자 + "전체 보기" → 모달)
- 위험성평가 연계 (제목 + 상태 배지)
- 첨부 자료 수, 등록일 등

### 2.3 참여자 그리드

| 컬럼 | 설명 |
|---|---|
| NO | 출결 번호 또는 순번 |
| 이름 | userNm |
| 타입 | "정규직" / "일용직" 배지 |
| 입실 | entryAt (시:분) |
| 종료 | exitAt (시:분), 빈 칸이면 "미종료" |
| 이상신호 | 요약 (없으면 "-") |
| 이수 | ✓ / ✕ 아이콘 |
| 액션 | 📋 (이벤트 로그 보기), ✏️ (미이수 처리, W-14) |

**행 색상:**
- 정상 이수: 흰색
- 이상 신호 있음: 노란 톤
- 미이수: 빨간 톤
- 강제 종료 (관리자 처리): 회색 톤

### 2.4 이벤트 로그 토글 (행 펼치기)

📋 아이콘 클릭 시 행 아래로 펼쳐지는 형태 또는 별도 모달:

```
┌──────────────────────────────────────────────────┐
│  김철수 - 이벤트 타임라인                          │
│  ─────────────────────────────────────────────  │
│  08:02:00  ENTER                                  │
│  08:02:01  START (관리자 시작 인지)                │
│  08:03:15  GPS_UPDATED (37.5664, 126.9782)        │
│  08:05:30  BACKGROUND_IN                          │
│  08:06:50  BACKGROUND_OUT (1분 20초)              │
│  08:08:00  BACKGROUND_IN                          │
│  08:09:30  BACKGROUND_OUT (1분 30초)              │
│  ...                                              │
│  08:15:00  SIGNATURE_STARTED                      │
│  08:15:05  END                                    │
│                                                  │
│  요약: 백그라운드 5회 (총 8분), GPS 정상           │
└──────────────────────────────────────────────────┘
```

### 2.5 요약 vs 상세 토글

- 기본: **요약 표시** (이상신호 컬럼에 짧은 텍스트)
- 📋 클릭 시 **전체 타임라인** 표시
- 분쟁 발생 시 증빙 자료로 활용

### 2.6 서명 미리보기

- 입실 서명, 종료 서명 이미지 클릭 시 라이트박스로 확대
- 강제 종료(서명 없음)는 "서명 없음 (관리자 강제 종료)" 표시

### 2.7 데이터 바인딩

**세션 정보:** `GET /api/web/tbm/sessions/{eduSessionNo}` 또는 history API
**출결 명단:** `GET /api/web/tbm/sessions/{eduSessionNo}/attendances` (`03_BACKEND_SPEC_WEB.md §7.2`)
**이벤트 로그:** `GET /api/web/tbm/attendances/{attendanceNo}/events` (`§7.3`)

### 2.8 사용성 요구사항

- **인쇄용 레이아웃**: 인쇄 시 컬럼/요약 깔끔하게 (CSS @media print)
- **검색·필터**: 이름 검색, 타입 필터, 이수 상태 필터
- **정렬**: 입실 시각, 이름, 이수 상태별 정렬
- **다운로드**: 출결 명단 Excel/PDF

## 3. W-14: 미이수 처리 (수정 모달)

### 3.1 진입 경로

- W-13 출결 그리드의 ✏️ 버튼
- W-11에서 미종료자 강제 종료 시 (이때는 W-11 통합)

### 3.2 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│  출결 상태 변경 - 김철수                          [X]   │
├─────────────────────────────────────────────────────────┤
│  현재 상태: ✓ 이수                                       │
│  입실: 08:02  │  종료: 08:15                             │
│  종료 유형: 본인 (SELF)                                  │
│                                                          │
│  📋 변경할 상태 *                                        │
│  [○ 이수 (COMPLETED)]  [● 미이수 (NOT_COMPLETED)]       │
│                                                          │
│  📝 사유 * (필수 입력)                                   │
│  ┌───────────────────────────────────────────────┐    │
│  │ 동료 진술 결과 30분간 자리 비웠음 확인.          │    │
│  │ 휴게실에서 발견됨.                              │    │
│  └───────────────────────────────────────────────┘    │
│                                                          │
│  ⓘ 변경 이력이 영구 기록됩니다.                          │
│  ⓘ 이전 상태로 다시 변경할 수도 있습니다.                 │
│                                                          │
│  변경 이력:                                              │
│  • 5/1 08:15: COMPLETED (자동, 본인 종료)                │
│  • 5/2 09:00: NOT_COMPLETED (김안전, 동료 진술 확인)     │
│                                                          │
│           [취소]              [상태 변경]                │
└─────────────────────────────────────────────────────────┘
```

### 3.3 검증

- **사유 필수**: 10자 이상
- **변경 권한**: 개설자, safe, master

### 3.4 데이터 바인딩

**호출:** `PUT /api/web/tbm/attendances/{attendanceNo}/completion` (`03_BACKEND_SPEC_WEB.md §7.4`)

```json
{
    "completionStatusCd": "NOT_COMPLETED",
    "reason": "동료 진술 결과 30분간 자리 비웠음 확인. 휴게실에서 발견됨."
}
```

### 3.5 변경 이력 표시

- `TB_EDU_ATTENDANCE.STATUS_UPDATED_BY` / `STATUS_UPDATED_AT` 컬럼 활용
- **단 다중 변경 이력 표시는 별도 테이블 필요** (현재 DDL은 마지막 변경만 저장)
- MVP에선 마지막 1회만 표시. 다중 이력은 Phase 2 (`TB_EDU_ATTENDANCE_HISTORY` 추가)

### 3.6 처리 후 동작

- 성공 시 토스트
- W-13 그리드 즉시 갱신 (해당 행 색상·아이콘 변경)
- 모달 닫기

## 4. W-15: 사용자별 TBM 이수 이력

### 4.1 진입 경로

- 인사 모듈에서 특정 직원 조회 시 "TBM 이수 이력" 탭
- 또는 W-13에서 사용자 이름 클릭 시
- 또는 직접 URL: `/tbm/history/users/{userId}`
- 일용직: `/tbm/history/daily-users/{dailyUserNo}`

### 4.2 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  홍길동 (생산1팀)  - TBM 이수 이력         [📥 다운] [닫기] │
├─────────────────────────────────────────────────────────────┤
│  [기간: 2026/1/1~2026/5/31] [이수 상태▼] [조회]            │
│                                                              │
│  📊 통계                                                     │
│  총 22회 │ 이수 21회 (95.5%) │ 미이수 1회                   │
│                                                              │
│  ┌────┬────────────┬──────┬──────┬───────┬─────┬──────┐│
│  │ NO │ TBM 제목     │ 사업장│ 일자  │입실/종료│이수 │ 액션 ││
│  ├────┼────────────┼──────┼──────┼───────┼─────┼──────┤│
│  │ 1  │ 5월 1주차    │A공장│ 5/1  │08:01-15│  ✓  │  🔗  ││
│  │ 2  │ 4월 4주차    │A공장│ 4/29 │08:02-15│  ✓  │  🔗  ││
│  │ 3  │ 4월 3주차    │A공장│ 4/22 │08:05-15│  ✕  │  🔗  ││
│  │    │  └ 미이수 사유: 동료 진술 결과...                  ││
│  │ 4  │ 4월 2주차    │A공장│ 4/15 │08:00-15│  ✓  │  🔗  ││
│  └────┴────────────┴──────┴──────┴───────┴─────┴──────┘│
│  [< 이전]  1 2 [다음 >]                                     │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 통계 영역

| 지표 | 계산 |
|---|---|
| 총 참여 | 입실한 모든 TBM |
| 이수 횟수 | COMPLETION_STATUS_CD = 'COMPLETED' |
| 미이수 횟수 | COMPLETION_STATUS_CD = 'NOT_COMPLETED' |
| 이수율 | 이수 / 총 참여 × 100% |
| 평균 참여 시간 | 평균(EXIT_AT - ENTRY_AT) |

### 4.4 컬럼 정의

| 컬럼 | 표시 |
|---|---|
| NO | 순번 |
| TBM 제목 | session.title |
| 사업장 | site_nm |
| 일자 | session 시작일 |
| 입실/종료 | `{entryAt:HH:mm}-{exitAt:HH:mm}` 또는 "강제 종료" |
| 이수 | ✓ / ✕ + (미이수 사유 펼치기) |
| 액션 | 🔗 → 해당 TBM 출결 상세(W-13)로 이동 |

### 4.5 위험성평가 연계 표시 (선택)

각 행 우측 또는 펼침 영역에 해당 TBM의 위험성평가 연계 표시:
- 이 사용자가 어떤 위험에 대해 교육받았는지 추적 가능
- **Phase 2 사고 관리 모듈의 기반 데이터**

### 4.6 데이터 바인딩

**호출:** `GET /api/web/tbm/history/users/{userId}/attendances` (`03_BACKEND_SPEC_WEB.md §7.5`)

또는 일용직:
**호출:** `GET /api/web/tbm/history/daily-users/{dailyUserNo}/attendances`

### 4.7 사용성

- **PDF 출력**: 사용자별 TBM 이수 증명서 (Phase 2)
- **알림**: 미이수 N회 이상 시 알림 (Phase 2, 관리자에게)
- **정기 교육 진행률** (Phase 2): 반기 6~12시간 누적 표시

### 4.8 권한

- master, safe: 모든 사용자 조회
- 사업장 관리자: 자기 사업장 사용자만
- 본인: 본인 이수 이력 조회 가능 (앱에서 — 본 화면은 관리자용)

## 6. Excel/PDF 출력 가이드

### 6.1 W-12 출력 (이력 목록)

**Excel 시트 구성:**
- 시트 1: 세션 요약 (제목, 사업장, 종료일, 참여수, 이수수, 이수율, 위험성평가 연계)
- 시트 2~N: 세션별 출결 상세 (사용자명, 입실/종료, 이수 상태)

**PDF 보고서:**
