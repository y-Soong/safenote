\## User\_01.vue 화면 수정요청

&#x20;

* 신규 계정 생성용 기능과 신규 계정 대량 생성용 엑셀 업로드 기능좀 만들줘
* 대량 계정 생성 기능의 경우 사업장 값은 SITE\_NO 기준 입력을, 소속의 경우는 NODE\_CD를 기준으로 입력하게끔 만들어줘

  * NODE\_CD의 경우 지금 웹 화면엣허 정리하여 사용자에게 보여주는 화면이 없는데 추후 개발할거야.
* 관리자가 생성해주는 계정의 경우 휴대폰번호 인증이 안된 상태니 추후 사용자가 로그인할 때 생성된 휴대폰 번호로 인증을 받도록 해줘.
* 경력인정 부분도 엑셀 업로드에 같이 들어가야해.
* 엑셀 업로드 폼도 직접 만들어주고 양식다운로드 > 관리자가 다운받은 양식에 데이터를 채우는 작업 > 엑셀 업로드 프로세스로 진행해줘
