## 연차 부여 정책(Baim_07.vue) 화면 수정 요청의 건

1. 회사가 허용하는 사용 단위(다중 선택)에 대한 수정요청
	- 지금은 1일(전일), 0.5(반차), 시간차(2시간), 시간차(1시간), 시간차(30분)형태의 체크박스 형태로 제공하고 있는데 이를 라디오 버튼형태로 바꾸고 싶어.
	- 연차 타입 관리 (Attd_03.vue) 화면에서 연차를 생성할 때 처럼 사용 단위를 1개로 고정하고 싶어
	- 어차피 해당 연차를 사용할 때 설정된 단위를 기준으로 복수개를 등록할 수 있도록 구조를 잡을거거든
	- 예를들어 사용 단위가 30분 이라면 시작 시간을 설정하고 30분 단위로 늘려나가면서 여러개의 연차를 등록할 수 있도록 할거기 때문이야.
	- 관련해서 "같은 날 다중 신청" 부분도 없어져야 할거같아.
	- 예를들어 스케줄이 9 - 18면 연차 타입을 선택하고 해당 연차 타입에서 제공하는 단위(예를들어 시간차(1시간))를 선택하고 시작시간을 13시로 지정한 뒤 up, down 버튼을 통해서 연차 사용 단위만큼 연차 종료시간을 자동 지정해주는 방식으로 모바일을 개발할거야.
	- 상기 규칙에 맞춰서 영향도가 있을만한 부분을 판단해서 일괄 수정해줘
