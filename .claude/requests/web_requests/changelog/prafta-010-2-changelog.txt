TB_USER_ATTD_REQ.REQ_TYPE / REQ_STATUS 코드값(SYS032/SYS033) 전환

[요약]
TB_USER_ATTD_REQ 의 REQ_TYPE / REQ_STATUS 를 enum 문자열(ATTD_MODIFY, REQUESTED 등)
에서 TB_SYST_VAL_D 의 SYST_VAL_CD 'SYS032'(요청 유형) / 'SYS033'(요청 상태) 코드값으로
전환했다.

[확정 매핑]
- REQ_TYPE  (SYS032): ATTD_CREATE->'01' / ATTD_MODIFY->'02' / OT_REGISTER->'03'
                       (04 초과근무수정 / 05 연차사용 / 06 연차수정 은 SYS032 정의만 존재,
                        현재 코드 미매핑)
- REQ_STATUS(SYS033): REQUESTED->'01' / APPROVED->'02' / REJECTED->'03' / CANCELLED->'04'
