================================================================================
PRAFTA-012 변경 이력 (changelog)
TB_USER_ATTD_GPS.GPS_INFO_TYPE 컬럼 적용 - 지도 좌표 출근/퇴근 구분
작성일: 2026-05-18
================================================================================

[요약]
TB_USER_ATTD_GPS 테이블에 추가된 GPS_INFO_TYPE 컬럼('01'=출근 / '02'=퇴근)을
GPS 좌표 조회 API와 지도 렌더 화면에 반영했다. 기존에는 좌표 배열의 첫 점을
출근, 마지막 점을 퇴근으로 "위치 추론"했으나, GPS_INFO_TYPE 코드값 기준으로
출근/퇴근 마커 색·라벨을 결정하도록 교체했다.

[사용자 확인 사항 (정책서보다 우선)]
- 마커 구분 : '01'->출근 마커(초록 #16a34a)+"출근" 라벨,
              '02'->퇴근 마커(빨강 #ef4444)+"퇴근" 라벨.
- NULL 처리 : GPS_INFO_TYPE 이 '01'/'02' 가 아닌(NULL 포함) 좌표는 지도에
              표시하지 않는다.
- 폴리라인   : 출근-퇴근 2점 연결선은 유지.
- 행 개수    : 한 ATTD_ID 당 GPS_INFO_TYPE 별 0~1건(총 0~2점).
              중간 동선 점(dot) 개념 없음.
- Attd_08    : Mock 좌표 색 구분(빨강 마커) 제거. 단 하단 "Mock 좌표 N건 포함"
              요약 텍스트와 mockedCount 계산은 유지.

[DB 변경]
- 없음. GPS_INFO_TYPE 컬럼은 사용자가 DB 에 이미 추가 완료(작업 외부).
  마이그레이션 SQL 작성 불필요.
- 주의: 본 세션은 MCP MySQL(prafta-mysql) 미연결이며 .claude/context/schema-full.sql
  스냅샷에는 GPS_INFO_TYPE 이 아직 미반영. 추후 스냅샷 재생성 필요.
  컬럼 정의 전제: GPS_INFO_TYPE char(2), 값 '01'/'02', NULL 가능.

================================================================================
§2. QA 후속 수정 (경미 UX 이슈 해소)
================================================================================
QA 1차 검증에서 발견된 경미 이슈를 사용자 결정("수정한다")에 따라 반영.

[이슈] 한 ATTD 의 GPS 행이 전부 gpsInfoType NULL(또는 01/02 아님)일 때,
       좌표는 전부 필터링되지만 "수집된 GPS 좌표가 없습니다" 안내는
       trail.length===0 조건이라 노출되지 않고 빈 회색 지도 캔버스만 표시됨.

[조치]
  AttdGpsCoordPanel.vue:
    - validTrail computed 신규: gpsInfoType 이 '01'/'02' 인 좌표만 추림.
    - 빈-상태 v-else-if 조건 trail.length===0 -> validTrail.length===0.
    - 요약 v-if / 표시 건수 trail.length -> validTrail.length.
    - mockedCount 산정 기준을 props.trail -> validTrail(실제 표시 좌표)로 변경.
  Attd_08.vue:
    - validGpsList computed 신규: 동일 필터.
    - 빈-상태 v-else-if 조건 gpsList.length===0 -> validGpsList.length===0.
    - 요약 v-if / 표시 건수 gpsList.length -> validGpsList.length.
    - mockedCount 산정 기준을 gpsList -> validGpsList 로 변경.
