## 브라우저 다중탭과 관련된 요청

1. 브라우저 탭과 관련된 요청
 - 문제 상황 : 브라우저에서 서비스에 접속 후 로그인(http://localhost:8081/main) > 임의의 메뉴를 클릭(http://localhost:8081/main/Attd_05) > 브러우저에서 탭을 하나 더 열고 현재 url 주소(http://localhost:8081/main/Attd_05)를 동일하게 입력 > 404 에러
 - 수정 요청안 : 기존 탭에서 세션이 유지되어 있는 상태라면 http://localhost:8081/main 으로 라우팅, 유지되고 있는 세션이 없다면 http://localhost:8081 으로 라우팅
