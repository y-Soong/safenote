\## 일일사용자 회원가입용 신규 화면 개발



1. 해당 화면은 일일 사용자들이 url 접근 혹은 QR코드 스캔으로 접근하게되는 외부용 화면임

&#x20;- 동작구조에 대해서 설명하면 Baim\_05.vue 화면에서 제공하는 기능인 링크복사, QRCODE 두 기능을 통해 일일사용자는 회원가입 화면으로 접근할 수 있다.



&#x20;- 관리자는 Baim\_05.vue 에서 링크를 복사해서 일일 사용자에게 전달하거나 QRCODE를 출력해서 사업장에 오프라인으로 걸어놓고 회원가입을 받는다.



&#x20;- 기능 특성상 회원가입 창 처럼 로그인 안하고 접근가능해야 한다.



&#x20;- 일일 사용자는 회원가입 시  TB\_DAILY\_USER 테이블에 정보를 저장한다.



&#x20;- 일일 사용자 회원가입 창에는 아래 정보 들이 표시 및 기입된다.

&#x20; 1) 회사정보 : 수정X, 링크 혹은 QRCODE 스캔을 통해 URL주소를 받으면 http://localhost:8081/dailyUserJoin/001-00001 이런 형태일텐데 001은 회사코드 뒤에 5자리 숫자는 사업장 코드이다. (항상 이 형식 유지) 화면이 열리면 전달받은 값을 통해 API 통신으로 회사명을 불러와 세팅한다.

&#x20;# 보안상 허술할 수 있지만 회사코드가 추후 높은 복잡도와 긴 문자열로 제공될 것이라서 어느정도 보완될것이라고 봄(혹시 해당구조에 문제가 있을경우 대화방식으로 신규 방안을 함께 모색)

&#x20; 2) 사업장 정보 : 수정x, 회사정보와 마찬가지로 url로 전달받은 값을 통해 API 통신 후 사업장명 세팅

&#x20;3) 사용자ID : 직접 입력(중복체크 기능 필요, USE\_YN 값이 'Y'인 값들 중에서만 체크해주면 됨)

&#x20;3) 사용자이름 : 직접 입력

&#x20;4) 핸드폰번호 : 직접 입력(중복체크 기능 필요, USE\_YN 값이 'Y'인 값들 중에서만 체크해주면 됨 )



&#x20;- 상기 정보 외 회원가입 API에서 처리할 내용 

&#x20;1) USER\_CD : CONCAT('D', DATE\_FORMAT(NOW(), '%Y%m%d'), FNC\_CMM\_SEQ\_NEXTVAL(#{cmpnyCd}, 'DAILY\_USER')) 값으로 넣어주면 됨

&#x20;2) REG\_TYPE : '01' 로 고정 (상태 값 '직접가입'을 의미하며 해당 링크를 통해 회원가입시에는 고정적으로 '01'이 들어간다.)

&#x20;3) ACCOUNT\_STATUS : '01'로 고정(상태 값 '활성화'를 의미하며 추후 개발할 배치에서 자정마다 만료로 바꿀예정)

&#x20;4) WORK\_EXPIRE\_DATE : 회원가입 당일날로 데이터 입력 (YYYYMMDD)



&#x20;- 그 외에 휴대폰번호 암호화나 비밀번호 암호화 등은 LoginServiceImpl에 insertUserInfo 함수 참고



&#x20;- 화면 UI는 JoinUserPop.vue를 참고한다. (모바일에서 주로 접근할 화면이기 때문에 모바일 친화적이여야 하고 화면크기가 서로다른 모바일 기기의 특성상 반응형으로 화면이 만들어져야 한다.)



&#x20;- 회원가입 하단에 이용약관 동의 기능이 있어야 한다. (TermsPop.vue 참고)



&#x20;- 백앤드, 프론트앤드 개발 모두에 대한 작업 요청이며 파일을 어디에 생성하는게 적절할지 직접 판단해서 사용자에게 추천한다.

&#x20;# 사용자는 claude code의 추천경로를 확인하여 최종 컨펌한다. (claude code는 사용자의 컨펌 후 해당 경로에 작업)
