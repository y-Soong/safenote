## 12. 스케줄 마감

### 12.1 개요

스케줄 마감은 특정 조직·기간의 스케줄 데이터를 확정하는 작업이다. 마감 후에는 스케줄 생성/수정이 제한된다.

### 12.2 마감 처리

- 마감 단위: 조직(노드) + 기간(월 단위)

- 마감 권한: 별도 마감 권한 보유자만 실행 가능 (공동 처리 범위 미포함)

- 마감 후 변경은 마감 해제 → 수정/승인 → 재마감으로 처리

### 12.3 스케줄 마감 화면 기능

- 조직 트리 기반 대상 조직 선택

- 마감 대상 기간(월) 선택

- 마감 전 미결 항목(대기 요청) 현황 확인

- 마감 실행 / 마감 해제

- 마감 이력 조회

스케줄 마감은 근태 마감의 선행 조건이다.
