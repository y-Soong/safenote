## 7. 출퇴근 정책

### 7.1 기본 규칙

- 근로자는 근무 시작 시 출근, 종료 시 퇴근을 모바일 앱에서 등록

- 하루 출근/퇴근은 최대 2회(스케줄 구간 수와 무관) — prafta-app-014

- 출근 가능 횟수는 하루 2회 상한 (5장 참조)

### 7.2 GPS 지오펜스 판정

- 사업장 관리에서 설정된 GPS 허용범위(미터)를 기준으로 판정

- 사업장 내부: 정상 출근으로 기록

- 사업장 외부: "근무지 외" 태그로 기록 (정산값 자동 변경 없음)

→ 사업장 GPS 허용범위 설정은 공통 정책서 6장 참조

### 7.3 GPS 미확인 처리

- GPS 수신 불가·권한 거부·오프라인 등으로 위치 확인이 어려워도 출퇴근 등록은 허용

- 단, 기록은 "GPS 미확인(확인 필요)" 상태로 표시

- 확인 필요는 근태 마감 차단 사유이며 마감 전 반드시 해소

- 해소는 근태 보정 요청-승인으로 처리

### 7.4 오류 / 누락 / 중복 처리

- 출근만 또는 퇴근만 존재, 순서 이상, 3회 이상 기록 등은 근태 보정 요청으로 확정

- 원본 로그는 삭제하지 않음 (보정 이력만 추가)

### 7.5 스케줄 없는 날의 근무

- 출퇴근 등록은 허용하되 하루 2회까지로 제한(2회 초과는 차단, 초과근무 상신 대상) — prafta-app-014

- 해당 일자의 근무는 전량 추가근무로 취급

- 추가근무 상신 및 승인 필수

- 미승인 시 근태 마감 차단
