## 13. 근태 마감

### 13.1 개요

근태 마감은 특정 조직·기간의 근태 데이터를 최종 확정하는 작업이다. 마감 후 정산 데이터가 급여/인사 처리의 기준이 된다.

### 13.2 마감 순서

스케줄 마감 → 근태 마감 (스케줄 마감 선행 필수)

### 13.3 근태 마감 차단 조건

| 차단 사유 | 해소 방법 |
| --- | --- |
| 미결(대기) 요청 | 스케줄/근태/휴가/추가근무 요청 승인 또는 반려 |
| GPS 미확인 미해소 | 근태 보정 요청-승인으로 해소 |
| 미승인 추가근무 | 추가근무 승인 또는 반려 (스케줄 없는 날 근무 포함) |

### 13.4 근태 마감 화면 기능

- 조직 트리 기반 대상 조직 선택

- 마감 대상 기간(월) 선택

- 차단 사유별 미결 항목 현황 조회 (미결 요청 건수, GPS 미확인 건수, 미승인 추가근무 건수)

- 해당 항목으로 바로가기 (개별 처리 유도)

- 마감 실행 / 마감 해제

- 마감 이력 조회

마감/해제 권한은 공동 처리 범위에 포함되지 않으며 별도 권한으로 통제한다.
