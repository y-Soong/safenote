## 16. 운영 시나리오

### 16.1 표준 업무 흐름

- 조직도 구성 → 노드 관리자 지정 (공통 정책서 7장)

- 근무 타입 및 교대 스케줄 패턴 설정

- 연차 타입, 휴일, 출퇴근 표준화 단위 설정

- 기본 스케줄 설정 → 연간 스케줄 자동 생성

- 월 운영: 스케줄/휴가 등록, 근로자 요청 접수 → 승인/반려

- 출퇴근 등록 → 근태 산정 (구간 수 기반 출근 제한 적용)

- 초과근무 상신 (사전 또는 사후 5일 이내) → 승인

- 오류/예외는 근태 보정 요청 → 승인

- 스케줄 마감 → 차단 사유 해소 → 근태 마감

- 리포트/정산 반영 → 예외는 마감 해제 후 재처리
