## 3. 근무 유형 관리

### 3.1 개요

근무 유형은 정규 근무의 기본 단위다. 관리자 웹의 "근무 타입 관리" 화면에서 생성·수정·관리한다.

### 3.2 근무 유형 구성 요소

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 근무코드 | 필수 | 사업장 내 고유 코드(예: ST001) |
| 근무구간 | 필수 | 1구간 / 2구간 |
| 1 근무시간 | 필수 | 첫 번째 근무 구간의 시작/종료 시간 |
| 1 휴게시간 | 선택 | 첫 번째 구간의 자동 공제 분(예: 90분) |
| 2 근무시간 | 2구간 시 필수 | 두 번째 근무 구간의 시작/종료 시간 |
| 2 휴게시간 | 선택 | 두 번째 구간의 자동 공제 분 |
| 사용여부 | 필수 | 사용 / 미사용 |
| 기본근무여부 | 선택 | 사용 / 미사용. 신규 사용자 기본값 지정 여부 |

### 3.3 운영 규칙

- 자정 경계 근무(예: 1500-2400, 0000-0700) 허용

- 2구간 시 구간 겹침 금지 (구간1 종료 ≤ 구간2 시작)

- 근무 유형 삭제는 배정된 근로자가 없는 경우에만 가능 (또는 비활성화)

- 근무 유형 수정은 마감된 기간에는 소급 적용되지 않음

- 변경 이력은 모두 보존 (변경이력 버튼으로 조회)
