## 10. 근태기록 산정 규칙

### 10.1 정규 근무 계산

스케줄 구간을 기준으로 정규 근로시간을 산정한다. 예시(스케줄 09:00-18:00):

- 실제 출근이 09:00보다 빠르더라도 정규 시작은 09:00으로 계산

- 실제 퇴근이 18:00보다 늦더라도 정규 종료는 18:00으로 계산

- 실제 출근이 늦으면 지각 발생 (예: 09:03 → 3분 지각)

- 실제 퇴근이 빠르면 조퇴 발생 (예: 17:45 → 15분 조퇴)

### 10.2 출퇴근 시간 표준화

- 시작 시간과 종료 시간의 표준화 단위를 각각 독립 설정

- 단위 옵션: 설정안함 / 5분 / 10분 / 15분 / 30분

- 설정 방식: "출퇴근 시간 표준화" 화면

#### 10.2.1 적용 예시 (시작 단위 30분)

- 08:45 출근 → 정규 계산상 09:00 출근으로 처리

- 09:10 출근 → 정규 계산상 09:00 출근으로 처리 (다음 30분 경계까지 반올림/내림은 시작/종료 방향에 따름)

#### 10.2.2 변경 이력

- 표준화 단위 변경 시 변경 이력 자동 기록 (누가/언제/어떤 값으로)

- 실제 출퇴근 시각은 유지되며, 계산에만 반영

### 10.3 추가근무(초과근무) 인정 및 계산

- 면제 시간: 정규 구간 밖 초과분에서 먼저 제외되는 분. 출퇴근 시간 표준화 단위와 연동

- 추가근무 시간 표준화 단위: 관리자가 5/10/15/30분 중 설정

- 계산식: (초과분 - 면제시간)을 추가근무 표준화 단위로 산정

#### 10.3.1 계산 예시 (출퇴근 단위 30분, 추가근무 단위 15분)

| 퇴근 시각 | 초과 분 | 추가근무 산정 |
| --- | --- | --- |
| 18:30 | 30분 | 0분 (전량 면제) |
| 18:59 | 59분 | 15분 (59-30=29 → 15분 단위) |
| 19:00 | 60분 | 30분 (60-30=30 → 30분 단위) |
| 19:31 | 91분 | 60분 (91-30=61 → 60분 단위) |

### 10.4 자동 휴게시간 공제

- 휴게시간은 자동 공제만 운영 (수동 입력·예외 승인 없음)

- 적용 기준은 정규 근무시간 (추가근무 제외)

- 공제 규칙은 근무 유형별 설정값 적용

- 규칙 변경 시 시행일/적용 범위 공지
