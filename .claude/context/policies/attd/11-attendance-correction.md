## 11. 근태 보정

### 11.1 보정 대상

- 출퇴근 누락/중복/순서 오류/3회 이상 기록

- 시간 단위 휴가일 구간 오류 (퇴근 미처리 등)

- 일자 귀속 문제 (교대/자정 경계)

- GPS 미확인(확인 필요) 해소

- 기타 정산 확정 필요 예외

> 변경 이력: 2026-05-31 (prafta-app-013) — 종전 "초과근무 5일 상신 기한 경과분" 항목을 삭제. D+5일 사후 상신 기한이 폐기(근태 마감 전까지로 통일, §9.3 / 요청승인관리 재기획서 §3.2)되어 해당 항목의 의의가 소멸했다.

### 11.2 신청 시점 (모바일 앱)

| 항목 | 내용 |
| --- | --- |
| 신청 주체 | 근로자 (모바일 앱) |
| 신청 시점 | **과거·현재만 신청 가능. 미래(아직 도래하지 않은 일자) 차단.** |
| 오늘 진행 중 | 오늘 근무 진행 중(출근했으나 전 구간 미완료)이면 보정 비활성. |
| 마감 제한 | 해당 일자 근태 마감 후 신청 불가 |

> 변경 이력: 2026-05-31 (prafta-app-013) — 모바일 앱 근태 보정 신청 게이팅을 명시: 미래 제외(과거·현재만), 오늘 근무중 제외, 미마감. 기존 서술과 충돌하면 본 결정을 우선한다. (앱 게이팅 산출 = `AppAttd01ServiceImpl` 4액션 산출 로직 `canRequestAttendanceCorrection = !isFuture && !closed && !isWorking`)

### 11.3 요청/승인

- 요청 필수 입력: 대상자/일자/구간, 수정 내용, 사유, 증빙(필요 시)

- 승인/반려 사유 필수, 이력 보존

- 선점(처리 잠금) 적용
