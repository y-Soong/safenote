## 5. 출퇴근 횟수 및 구간 제한

### 5.1 기본 원칙 — 스케줄 구간 기반

사용자의 1일 출근 가능 횟수는 해당 일자의 스케줄 구간 수를 따른다.

| 스케줄 | 최대 출근 가능 횟수 | 설명 |
| --- | --- | --- |
| 1구간 스케줄 | 1회 | 출근 → 퇴근 1쌍 |
| 2구간 스케줄 | 2회 | 출근 → 퇴근 → 재출근 → 퇴근 2쌍 |
| 스케줄 없음 | 제한 없음 | 단, 전량 추가근무 승인 필수 (7.5절 참조) |

### 5.2 재출근 조건

- 재출근(2번째 출근)은 반드시 이전 퇴근 완료 후에만 가능

- 이전 퇴근 없이 재출근 시도 시 시스템 차단

- 2번째 구간 스케줄 시작 전이어도 첫 구간 퇴근만 되어 있으면 재출근 허용

### 5.3 초과 출근 차단

- 스케줄 구간 수를 초과하는 출근 시도는 시스템이 차단

- 차단 시 사용자에게 "초과근무 상신으로 처리하세요"라는 안내 표시

- 3번째 이상 출근이 필요한 업무는 초과근무 상신으로 기록

→ 초과근무 상신은 9.3절 참조

### 5.4 예외 케이스 처리

| 상황 | 처리 |
| --- | --- |
| 스케줄 1구간인데 출근 1회 후 재출근 필요 | 초과근무 상신 |
| 스케줄 2구간인데 이미 출근 2회 완료 후 재출근 필요 | 초과근무 상신 |
| 퇴근 미등록 상태에서 재출근 시도 | 차단. 근태 보정 요청으로 해소 |
| 스케줄 없는 날 출근 | 허용 + 전량 추가근무 상신 필수 |
