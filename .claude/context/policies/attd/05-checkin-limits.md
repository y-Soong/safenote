## 5. 출퇴근 횟수 및 구간 제한

### 5.1 기본 원칙 — 하루 최대 2회 (prafta-app-014)

출근 가능 횟수는 스케줄 구간 수와 무관하게 **하루 최대 2회**로 한다. 2번째 출근은 일반 근무로 기록하며, 필요 시 해당 근무 전체를 초과근무로 사후 상신할 수 있다(§9.3).

| 스케줄 | 최대 출근 가능 횟수 | 설명 |
| --- | --- | --- |
| 1구간 스케줄 | 2회 | 1구간 출근→퇴근 후 추가 1회까지(2번째는 일반 근무, 스케줄 미대응=원본시각) |
| 2구간 스케줄 | 2회 | 출근 → 퇴근 → 재출근 → 퇴근 2쌍 |
| 스케줄 없음 | 2회 | 직전 퇴근 후 재출근 가능, 단 하루 2회 상한. 전량 추가근무 상신 대상(§7.5) |

### 5.2 재출근 조건

- 재출근(2번째 출근)은 반드시 이전 퇴근 완료 후에만 가능

- 이전 퇴근 없이 재출근 시도 시 시스템 차단

- 2번째 구간 스케줄 시작 전이어도 첫 구간 퇴근만 되어 있으면 재출근 허용

- **(예외, prafta-app-015) 2구간 스케줄**: 출근 시 사용자가 1구간/2구간을 명시 선택하므로(§5.5) 구간 순서가 자유롭다. 즉 1구간 퇴근 완료 여부와 무관하게 **다른 구간 출근이 허용**된다(예: 1구간 미퇴근 상태에서 2구간 출근 가능). 차단되는 것은 **동일 구간 중복 출근**뿐이다(각 구간 1회).

### 5.3 초과 출근 차단

- 하루 2회를 초과하는 출근 시도는 시스템이 차단

- 차단 시 사용자에게 "초과근무 상신으로 처리하세요"라는 안내 표시

- 3번째 이상 출근이 필요한 업무는 초과근무 상신으로 기록

→ 초과근무 상신은 9.3절 참조

### 5.4 예외 케이스 처리

| 상황 | 처리 |
| --- | --- |
| 1구간 스케줄에서 출근 1회·퇴근 후 재출근 | 허용(하루 2회 이내, 2번째는 일반 근무) |
| 하루 2회 출근 완료 후 추가 출근 필요 | 초과 차단 → 초과근무 상신 |
| 퇴근 미등록 상태에서 재출근 시도(1구간 스케줄·스케줄 없는 날) | 차단. 근태 보정 요청으로 해소 |
| (prafta-app-015) 2구간 스케줄에서 다른 구간 출근(이전 구간 미퇴근) | 허용(순서 자유, §5.2/§5.5). 동일 구간 중복만 차단 |
| (prafta-app-015) 2구간 스케줄에서 동일 구간 재출근 | 차단(`ATTD_400_088`, 각 구간 1회) |
| 스케줄 없는 날 출근(2회 이내) | 허용 + 전량 추가근무 상신 필수 |
| 스케줄 없는 날 2회 초과 출근 | 차단 → 초과근무 상신 |

### 5.5 2구간 출근 구간 선택 (prafta-app-015)

2구간(야간 2교대 등) 스케줄에서 출근할 때, 어느 구간으로 출근하는지를 **사용자가 직접 선택**한다. (구버전의 서버 시각 자동 추정 `isSecondSlotTimeWindow` 방식은 폐기.)

- **구간 선택 = WORK_SEQ**: 사용자가 선택한 구간이 곧 WORK_SEQ가 된다. 1구간 선택 → WORK_SEQ=1, 2구간 선택 → WORK_SEQ=2.
- **순서 자유**: 2구간을 먼저 등록하고 그 후 1구간을 등록하는 것도 가능(1구간 선행 강제 없음).
- **1구간 누락 허용**: 1구간 없이 2구간만 단독 등록 가능. 누락된 1구간은 근태 마감/보정 흐름으로 처리.
- **각 구간 1회**: 이미 등록한 구간은 다시 출근할 수 없다(버튼 비활성 + 서버 `ATTD_400_088` 차단). 구간 미선택 시 `ATTD_400_087`.
- **하루 2회 상한(§5.1) 유지**: 2구간 스케줄은 구간1+구간2 = 최대 2레코드로 자연 정합.
- (폐기) 구버전 §5.5 Case A/B/C·`confirmSkipPrevSlot`·`ATTD_400_084`(2구간 단독 소프트 차단)·`ATTD_400_085`(선행 1구간 미마감 차단)는 사용하지 않는다.
