## 4. 교대 근무 타입 관리

### 4.1 개요

교대 스케줄은 복수의 근무 유형을 반복 패턴으로 조합해 교대 근무를 운영한다. "근무 타입 관리" 화면의 "교대근무타입관리" 탭에서 관리한다.

### 4.2 구성 요소

| 항목 | 설명 |
| --- | --- |
| 교대 스케줄명 | 식별명(예: 3조 2교대, 4조 3교대) |
| 반복 주기 | 사이클 일수(예: 4일, 7일) |
| 일별 근무 유형 배정 | 사이클 내 각 일자별 근무 유형 또는 휴무 지정 |
| 적용 시작일 | 근로자의 교대 사이클 기준일 |
| 적용 대상 | 근로자 개인 또는 조직 단위 일괄 배정 |

### 4.3 운영 규칙

- 교대 스케줄 적용 시 해당 사이클에 따라 스케줄 데이터가 자동 생성

- 교대 패턴 수정 시 마감된 기간은 제외하고 미래 기간에만 반영

- 개별 날짜 수동 수정은 스케줄관리 화면에서 가능(사이클 유지)

- 교대 스케줄 각 구간도 1일 최대 2구간 제한을 따른다

- 적용/해제 이력은 모두 보존
