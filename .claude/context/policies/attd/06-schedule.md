## 6. 기본 스케줄 및 스케줄 관리

### 6.1 기본 스케줄

- 관리자는 근로자별 기본 스케줄(예: 09:00-18:00)을 설정

- 기본 스케줄은 연 단위 일괄 생성의 기준이 된다

- 교대 스케줄이 적용된 근로자는 교대 패턴이 우선

### 6.2 연간 스케줄 자동 생성

- 시스템은 근로자별 기본 스케줄을 기준으로 연간 스케줄 데이터를 일괄 생성

- 기본 스케줄 변경 시 마감된 기간을 제외한 미래 스케줄에 일괄 반영

### 6.3 미래 반영 시 덮어쓰기 옵션

- 미래 휴가 데이터는 모두 유지(고정)

- 수동 수정된 스케줄은 관리자 옵션으로 처리

- 덮어쓰기: 기본 스케줄로 재생성/재적용

- 유지: 기존 수동 수정값 유지

### 6.4 스케줄관리 화면 기능

- 사용자별·월 단위 캘린더 그리드 (구현됨)

- 사업장·소속부서·조회월·사용자명으로 필터

- 하위부서 조회 옵션

- 근무 타입 일괄 적용 (휴일 제외/포함 선택)

- 연차 타입 일괄 적용 (휴일 제외/포함 선택)

- 엑셀 양식 다운로드 및 엑셀 업로드 (일괄 등록)

### 6.5 스케줄 수정 경합 방지

- 근로자가 스케줄 수정 요청을 등록하여 대기 상태인 경우, 관리자는 해당 일자를 직접 수정할 수 없다

- 관리자는 요청을 먼저 승인/반려한 후 직접 수정 가능

### 6.6 1일 2구간 제한

- 스케줄은 1일 최대 2구간

- 2구간은 겹침 금지 (구간1 종료 ≤ 구간2 시작)
