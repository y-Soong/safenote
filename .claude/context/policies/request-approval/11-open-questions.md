# **11. 확인 사항 (Open Questions)**

- 일괄 승인 시 "조정 후 승인"을 일괄로 허용하지 않는다는 결정은 적절한가? (현 권고: 행별 시간이 다르므로 불허)

- 대기 누적 방지를 위해 "대기" 상태에서 기간 필터를 무시할지, 기본 12개월로 둘지 — 운영 데이터 확보 후 결정 권고

- 요청 처리 후 근로자 취소 요청 플로우 v2 도입 시 본 화면의 "취소 요청" 상태 별도 처리 필요 — 현재는 미도입

- 연차 다단 결재의 중간 반려·재상신 케이스를 v1에 포함할지 (현 권고: v1은 단일 반려 후 재신청)

- 근태 보정의 "조정 후 승인"에서 출퇴근 원본 로그 시각을 화면상 편집 가능하게 둘지 — 정책 §1.4는 원본 삭제·변조 금지. 권고: 원본은 read-only, 보정 결과만 편집

- 알림 배너의 "처리 필요 N건"이 가리키는 스코프 — 사용자 권한 스코프 전체 vs 현재 선택된 사업장만. 시안은 사업장 단위로 보이므로 사업장 단위로 통일 권고
