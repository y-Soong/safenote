# **3. 정책 정합성 점검**

현재 시안과 정책서 본문 사이의 4가지 정합 갭을 정리한다. (1)·(2)는 IA·메모리에 이미 반영된 결정 사항으로 정책 본문 재개정이 필요하고, (3)·(4)는 본 화면 기획 단계에서 즉시 반영해야 한다.

## **3.1 §9.6 화면 구성 — 3탭 → 4탭**

정책서 §9.6 인용: "관리자 웹의 통합 승인 화면은 3개 탭으로 구성된다. 스케줄 수정 요청 탭 / 초과근무 상신 탭 / 연차 상신 탭."

IA No.21은 이미 "스케줄 수정 / 초과근무 상신 / 연차 상신 / 근태 보정" 4탭 통합으로 갱신됨(보완 구분: 통합). 정책서 본문은 정식 개정 대기. 본 화면은 IA·메모리를 따라 4탭으로 설계한다.

## **3.2 §9.3.1 사후 상신 기한 — D+5일 → 사업장별 근태 마감 전까지**

정책서 §9.3.1 인용: "사후 상신 기한 — 근무일 기준 5일 이내". §9.3.2: "근무일 D에 초과근무 발생 → D+5일까지 상신 가능 / 5일 초과 시 상신 차단(단, 근태 보정 요청으로 예외 처리 가능)"

메모리 결정사항(2026-05-07): 사후 상신 기한은 **해당 일자의 근태 마감 전까지**. 사업장 마스터에 "근태 마감 기준일(매월 N영업일)" 속성이 추가되며, 본 화면은 시안에 표시된 "D-N영업일" 배지를 그대로 채택한다.

연동 변경: §11.1 보정 대상에서 "초과근무 5일 상신 기한 경과분" 항목은 의의가 소멸 → 정식 개정 시 삭제.

## **3.3 자동 마감 금지 · 강제 마감 미도입**

메모리 결정사항: 처리 필요 건이 남아 있으면 자동 마감 금지. 본 화면 우상단 알림 배너의 "처리 필요 N건 진행 중"은 **마감 차단 사유 카운터**로 동작하고, 마감 화면과 같은 데이터에 묶인다. 본 화면에는 강제 마감 액션을 두지 않는다.

## **3.4 v1 스코프 — 임금 정산 미포함**

상세 패널의 "승인 시 효과" 표현에서 임금·정산 언급은 모두 제거한다. 승인의 효과는 "근태기록의 결정 마킹"까지로만 기술한다. (메모리: project_prafta_v1_scope.md)
