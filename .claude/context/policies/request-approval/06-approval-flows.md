# **6. 케이스별 결재 플로우**

## **6.1 스케줄 수정 요청 (§9.2)**

근로자가 모바일 앱에서 특정 일자의 스케줄을 수정 요청 → 관리자가 본 화면에서 승인/반려.

| **단계** | **내용** |
| --- | --- |
| 신청 조건 | 해당 일자 스케줄 존재 + 스케줄 마감 전 |
| 필수 입력 | 대상 일자 / 변경 내용(시간·근무타입코드) / 사유 |
| 관리자 처리 | 요청대로 승인 / 조정 후 승인(시간·코드 수정) / 반려(사유 필수) |
| 승인 효과 | 해당 일자 스케줄 갱신 + 정산 재계산 트리거. 변경 이력 보존. |
| 수정 경합 | 대기 동안 관리자 직접 수정 잠금(§6.5) — 스케줄 관리 화면에서 본 일자는 잠금 표시 |
| 차단 사유 | ① 스케줄 마감 후 / ② 본인 결재 / ③ 다른 관리자 선점 |

## **6.2 근태 보정 요청 (§11)**

출퇴근 누락·중복·순서·3회 이상 기록·GPS 미확인·시간 휴가 구간 오류 등 정산 확정 필요 예외를 요청-승인으로 확정.

| **단계** | **내용** |
| --- | --- |
| 신청 조건 | 근태 마감 전 (마감 후이면 마감 해제 → 수정 → 재마감 플로우 — §1.4) |
| 필수 입력 | 대상자 / 일자·구간 / 수정 내용 / 사유 / (필요 시) 증빙 |
| 관리자 처리 | 요청대로 승인 / 조정 후 승인(보정 시각·구간 편집) / 반려(사유 필수) |
| 승인 효과 | 근태기록 보정 적용 — 출퇴근 원본 로그는 보존하고 보정 이력만 추가(§1.4·§7.4). GPS 미확인 해소. |
| 보정 유형 | 출퇴근 누락·중복·순서 오류·3회 이상 기록 / 일자 귀속(교대·자정 경계) / 시간휴가구간 오류 / GPS 미확인 해소 |
| 인라인 검증 | 조정 후 승인 시 §5(1일 최대 2구간·2회 출근) 적용. 위반 시 저장 차단. |

## **6.3 초과근무 상신 (§9.3)**

정규 근무 외에서 수행한 근무를 사전/사후로 상신.

| **단계** | **내용** |
| --- | --- |
| 상신 시점 | 사전 / 사후 모두 허용 |
| 사후 상신 기한 | 해당 일자의 근태 마감 전까지 (메모리 결정 — 정책 §9.3.1 정식 개정 대기) |
| 발생 케이스 | 조기 출근(스케줄 시작 전) / 연장(스케줄 종료 후) / 휴일·스케줄 없는 날 근무 / 구간 수 초과 출근 |
| 관리자 처리 | 요청대로 승인 / 조정 후 승인(시간 조정) / 반려(사유 필수) — §9.3.4 |
| 계산 비교 | 3단 비교(시스템 계산값 / 상신값 / 승인값) + 출퇴근 표준화 단위(§10.2)·면제 시간(§10.3) 안내 |
| 마감 연동 | 마감 도달 시 사후 상신 차단. 미승인 추가근무가 남아 있으면 근태 마감 차단 사유(§13.3) |

## **6.4 연차 상신 (§9.4)**

연차/반차/반반차/시간차/특별휴가 등 사용자 신청형 연차 타입의 신청을 처리.

| **단계** | **내용** |
| --- | --- |
| 신청 조건 | 해당 일자 스케줄 존재 + 잔여 연차 존재 + 근태 마감 전 |
| 관리자 처리 | 요청대로 승인 / 반려(사유 필수) — 시간 조정 없음 |
| 결재단계 | 연차 타입의 결재단계 설정에 따라 1~N단. HR최종승인 ON이면 마지막 단계가 HR |
| 승인 효과 | 해당 구간 휴가 적용 + 출근 차단(노무 수령 거부) — 일 단위는 출근 자체 차단, 시간 단위는 해당 구간 차단(§8.3) |
| 영향도 표시 | 잔여 카드(부여/사용/잔여) + 충돌(동일 구간 기존 휴가·출근 기록) + 시간 단위는 스케줄 구간 침범 여부 |
| 증빙 | 연차 타입의 증빙여부 ON이면 첨부 필수 — 미첨부 시 신청 단계에서 차단되어 본 화면에는 도달하지 않음 |
