# **1. 문서 개요**

## **1.1 작성 배경**

클로드 디자인이 산출한 시안(좌 리스트 + 우 상세 패널 2분할, 3개 탭)을 받았으나, **정책서 §9·§11 기준**과 비교했을 때 다음 정합성 갭이 있어 전면 재기획한다.

- 근태 보정(§11)이 별도 화면 가정으로 빠져 있어 IA(No.21)와 어긋남 — 정책서 본문 §9.6의 "3개 탭" 서술은 IA 갱신을 따라 4개 탭으로 정식 개정 대기 상태

- 초과근무 사후 상신 기한이 시안에는 D-N영업일(마감일까지)로 적용됐으나, 정책서 §9.3.1은 아직 "D+5일"로 명시 — 메모리 결정사항(마감일까지) 반영 대기

- 차단 사유(본인 결재·마감·선점·충돌)의 시각화·처리 흐름이 케이스마다 다르게 동작해야 하나 공통 규칙으로 묶이지 않음

- "결재" vs "승인", "상신" vs "신청" 표현이 혼재 — 정책서 공식 표현은 "승인/반려"·"신청/상신"이며 "결재"는 정책서 어디서도 쓰이지 않음
