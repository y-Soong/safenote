# **5. 화면 구조 (재기획)**

## **5.1 전체 레이아웃**

2분할 구조: 좌측 접수함(리스트) 60% / 우측 상세 패널 40%. 폭 1440 기준 좌 824px / 우 552px (gap 32px 포함). 공통 정책서 §13.2의 메인 컨텐츠 White 배경·primary tint LNB 규칙 적용.

| **영역** | **구성** |
| --- | --- |
| 상단 | 페이지 헤더(아이콘·타이틀·서브 설명) / 우측 상단 알림 배너(처리 필요 N건·마감 임박 D-N) / 필터 해제 단축 |
| 탭 영역 | 4개 탭(스케줄 수정 / 근태 보정 / 초과근무 상신 / 연차 상신) + 각 탭에 대기 건수 배지 |
| 필터 영역 | 조직(사업장/부서) · 사용자명 · 상태(대기/승인/반려/전체) · 기간 · 정렬(요청일시·마감임박순) |
| 접수함 | 체크박스 / 요청자 / 요청일시 / 대상 일자 / 요약 / 상태 / 마감(D-N영업일) |
| 일괄 처리 | 선택 N건 / 일괄 승인 / 일괄 반려 (동일 탭만 활성 — 후술 §7.7) |
| 상세 패널 | 요청 메타 / 검증·제약 / 요청 내용 비교(Before·After) / 사유·증빙 / 관리자 결정 / 처리 이력 |

## **5.2 페이지 헤더 ****&**** 알림 배너**

- 헤더 좌: 체크아이콘(Primary) + "요청 승인 관리" + 서브설명 "근로자가 등록한 요청을 검토하고 승인 또는 반려합니다."

- 헤더 우: 알림 배너. 사용자 조직 스코프 기준 "처리 필요 N건" + 마감 임박 사업장이 있으면 "사업장명 · YYYY년 N월 근태 마감 차단 · 처리 필요 N건". 클릭 시 해당 사업장+해당 월 필터로 전환 (§13.3 공통 차단 표시 원칙).

- 알림 배너 우측에 "필터 해제" 칩 — 모든 필터 초기 상태로 복귀.

## **5.3 탭 구성 — 4탭**

| **탭** | **정책** | **주 처리 결과** | **비고** |
| --- | --- | --- | --- |
| 스케줄 수정 요청 | §9.2 | 승인 → 스케줄 데이터 갱신 (근무 타입 코드 변경 포함) | 스케줄 마감 후 신청 불가. 대기 동안 관리자 직접 수정 잠금(§6.5). |
| 근태 보정 요청 | §11 | 승인 → 근태기록 직접 수정 (원본 로그는 보존, 보정 이력 추가) | §7.4(누락·중복·순서), §7.3(GPS 미확인), §8.4(시간 휴가 구간 오류) 모두 수용. |
| 초과근무 상신 | §9.3 | 승인 → 추가근무 정산 반영 (필요시 시간 조정 후 승인) | 사후 상신 기한 = 해당 사업장 근태 마감일까지(메모리 결정). 시스템 계산값·상신값·승인값 3단 비교. |
| 연차 상신 | §9.4 | 승인 → 휴가 적용 + 해당 구간 출근 차단(노무 수령 거부) | 잔여·충돌 영향도 표시. 연차 타입의 결재단계·HR최종승인 설정 반영. |

## **5.4 필터·검색·정렬**

- 조직 셀렉터: 사업장 / 전체 부서 — 사용자 스코프 내에서만 노출 (공통 §8.4 적용)

- 사용자명·사번 검색 입력

- 상태 세그먼트: 대기 N / 승인 / 반려 / 전체 — 기본 "대기"

- 기간 선택: 요청일시 기준. 기본 30일 이내. 단, "대기" 상태에서는 기간 무시 옵션 권고 (대기 누적 방지)

- 정렬: 기본 "요청일시 최신순". 보조 "마감 임박순(D-N영업일 작은 순)" — 마감 임박순은 처리 우선순위 가이드용

## **5.5 접수함 리스트 — 컬럼·정렬·시각화**

| **컬럼** | **너비** | **데이터** | **비고** |
| --- | --- | --- | --- |
| 선택 | 40px | 체크박스 | 차단 행(본인 결재·마감·다른 관리자 선점)은 disabled |
| 요청자 | 160px | 아바타+이름·소속 | 이름 클릭 시 사용자 미니 프로필 팝오버 (선택) |
| 요청일시 | 120px | YYYY-MM-DD HH:MM | 기본 정렬 기준 |
| 대상 일자 | 120px | YYYY-MM-DD (요일) | 구간 요청은 "YYYY-MM-DD~MM-DD" |
| 요약 | 가변 | 변경 요약 + 칩(유형) + 첨부 아이콘 | 탭별 포맷 §5.6.2 |
| 상태 | 110px | 대기·승인·반려·차단 | 차단인 경우 사유 칩 함께 표시 |
| 마감 | 110px | D-N영업일 / 마감 완료 | D-1 이하는 Danger, D-3 이하는 Amber 색상 |

### **5.5.1 행 상태 시각화**

- 일반 대기: 흰 배경 + 좌측 4px Primary 인디케이터

- 현재 선택된 행: 좌측 4px Primary 인디케이터 + Primary tint(#DCFCE7) 배경

- 차단(본인 결재·마감·선점): 행 텍스트 텍스트 컬러 약화(60%), 체크박스 disabled, 행에 사유 칩 표시

- 마감 임박: 마감 컬럼만 Amber/Danger, 행 자체는 일반 처리 — 데이터 무게가 너무 무거워지는 것 방지

### **5.5.2 탭별 요약 컬럼 포맷**

| **탭** | **요약 포맷 (예시)** |
| --- | --- |
| 스케줄 수정 | "정규 09:00-18:00 → 야간 18:00-04:00 (ST007→NT002) [사유 첨부]" — 칩: 변경 유형 |
| 근태 보정 | "퇴근 누락 → 퇴근 19:30 보정" 또는 "GPS 미확인 → 위치 확인" — 칩: 보정 유형(누락/중복/순서/GPS/시간휴가구간) |
| 초과근무 | "+1시간 30분 연장 / 사후 상신" — 칩: 연장/조기/휴일/스케줄없음, 사전/사후 |
| 연차 | "연차 1일 (휴가코드 AL001)" 또는 "반차 오후 4시간" — 칩: 연차타입명·유급/무급 |

## **5.6 일괄 처리 영역**

- "N건 선택됨 / 전체 N건" 텍스트 좌측. 우측에 "선택건 일괄 반려" / "선택건 일괄 승인" 버튼.

- 일괄 처리 가능 조건: (a) 모두 같은 탭, (b) 모두 대기 상태, (c) 본인 결재·마감·선점 차단 행 미포함.

- 일괄 승인 모달: 선택건 요약 리스트 표시 + 사유 입력(선택). 일괄 반려 모달: 반려 사유 10자 이상 필수(공통 정책서 §9.5). 일괄 처리시 행마다 동일 사유 적용.

- 체크박스 단축키: J/K (행 이동), A (선택 행 승인), R (선택 행 반려) — 시안 단축키 안내 유지.

## **5.7 상세 패널 — 공통 구조**

상세 패널은 모든 탭이 공유하는 6개 섹션을 갖는다. 섹션별 표시 내용은 탭에 따라 다르다(§5.8).

| **섹션** | **내용** |
| --- | --- |
| ① 메타 | 요청 유형 칩 / 상태 / 요청번호(REQ-…) / 요청자 카드(이름·소속·사번) / 요청일시·대상일자·마감(D-N영업일) |
| ② 검증·제약 | 처리 가능 / 본인 결재 차단 / 마감 후 / 선점 중 / 충돌 — 각 상태별 안내. (§9.5, §9.6.2, §13.3) |
| ③ 요청 내용 비교 | Before / After 시각화 (탭별 §5.8) |
| ④ 사유·증빙 | 요청자 사유 + 첨부 파일 리스트(이름·크기·미리보기). 분류 칩(연장근무/휴일근무/조기출근…) |
| ⑤ 관리자 결정 | 라디오 3개: 요청대로 승인 / 조정 후 승인 / 반려 + 사유 입력 + [처리하기] 액션. 결정 영역은 검증·제약 결과에 따라 비활성화. |
| ⑥ 처리 이력 | 상신·시스템계산·관리자처리·알림발송 순 타임라인 (공통 §13.3) |

## **5.8 상세 패널 — 탭별 차이**

### **5.8.1 스케줄 수정 요청**

- ③ 비교: 좌(현재 스케줄)·우(요청 스케줄) 카드 2분할. 시간 축(00-24h) 비교 바 + 근무 타입 코드 표시. 2구간 스케줄도 모두 표시.

- ⑤ 결정: "요청대로 승인" / "조정 후 승인"(이때 시간·근무 타입 코드 직접 편집) / "반려". 조정 시 §6.6의 2구간 겹침 금지, 자정 경계 허용 규칙 인라인 검증.

- 스케줄 마감 후이면 ② "마감 후 — 신청 자체가 불가했어야 함" 경고. ⑤ 비활성화.

### **5.8.2 근태 보정 요청**

- ③ 비교: 일자 단위 출퇴근 로그 타임라인. 원본 로그(보존)와 보정 결과(추가)를 분리 시각화. 정책 §1.4·§7.4 — 원본 삭제 금지 명시.

- ⑤ 결정: "요청대로 승인" / "조정 후 승인"(보정 시각·구간 직접 편집) / "반려". 조정 시 §5(1일 최대 2구간·2회 출근) 인라인 검증.

- GPS 미확인 해소의 경우, ② "GPS 미확인 — 마감 차단 사유"가 표시되며 승인 시 자동 해소.

### **5.8.3 초과근무 상신**

- ③ 비교: 시간 축 비교 — 스케줄·실제 출퇴근·상신값·승인값(4개 행) + 면제 30분 음영. ② 표준화 단위 적용 안내(§10.2, §10.3).

- 계산 비교 3단 카드: 시스템 계산값 / 근로자 상신값 / 관리자 승인값. 차이가 있을 경우 시안과 동일하게 +N분 배지 표시.

- ⑤ 결정: "요청대로 승인"(상신값 그대로) / "조정 후 승인"(시스템 계산값을 기본 채움, 직접 조정 가능) / "반려".

- 사후 상신: 메타에 "사후 상신" 칩 + "마감 D-N영업일 남음" 표시. 마감 시점 도달 시 ② 차단 — 정책 §9.3.1 변경 적용.

### **5.8.4 연차 상신**

- ③ 비교: 연차 타입(코드·유급/무급·단위) + 사용 구간 + 잔여(부여/사용/잔여) 카드. 충돌 영향도: 해당 구간의 기존 스케줄·휴가·출근 기록과의 충돌 여부.

- ⑤ 결정: 연차는 시간 조정 불가 — 라디오 2개("요청대로 승인" / "반려"). 단, 연차 타입 설정상 결재단계가 다단이거나 HR최종승인 ON이면 ② "HR 최종 승인 대기" 단계 표시.

- 마감 후이면 ② "마감 후 신청 불가" 안내. 잔여 부족이면 ② "잔여 N일 — 신청량 초과" 안내. 충돌이면 ② "충돌 — 동일 일자 기존 휴가 있음".
