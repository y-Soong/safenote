## 9. 선점(처리 잠금) 정책

### 9.1 목적

복수 관리자가 동일 건을 동시에 처리하여 발생하는 중복·충돌을 방지한다.

### 9.2 동작 방식

- 관리자가 처리 대상 건을 열면 해당 건은 선점 상태가 된다

- 선점 중에는 다른 관리자는 읽기만 가능(승인/반려/수정 불가)

- 완료(승인/반려/저장/취소) 시 즉시 해제

- 로그아웃·세션 종료·브라우저 종료 시 즉시 해제

- 타임아웃 없음, 강제 해제 기능 없음

### 9.3 적용 범위

- 근태: 스케줄 수정 요청, 추가근무 상신, 연차 신청 승인

- 근태 보정 요청 승인

- 산업안전: 시정조치 처리, 위험성평가 검토

- 기타 복수 관리자가 관여 가능한 모든 승인 화면

### 9.4 제외 범위

마감·해제 같은 단독 실행 액션은 선점 적용 대상이 아니며, 별도 권한으로 통제한다.
