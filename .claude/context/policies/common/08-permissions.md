## 8. 권한 체계

### 8.1 권한 결정 모델 — 3축 AND

사용자의 최종 접근 권한은 다음 세 가지 축의 교집합으로 결정된다.

| 축 | 결정 방식 | 관리 화면 |
| --- | --- | --- |
| 화면 권한 | 권한(Role)별 메뉴 × CRUD × 플랫폼 | 권한별 화면 제어 |
| 사업장 권한 | 사용자 × 접근 가능 사업장 매핑 | 사업장 권한 관리 |
| 조직 스코프 | 소속 사업장 vs 타 사업장 구분 규칙 | 조직관리 / 사용자관리 |

세 축 중 하나라도 차단되면 접근이 불가하다.

### 8.2 화면 권한 — 권한(Role) 관리

#### 8.2.1 기본 제공 권한

다음 3개 권한이 시드값으로 제공된다. 마스터관리자는 권한을 자유 생성·수정할 수 있다.

| 권한 | 성격 | 주 사용 맥락 |
| --- | --- | --- |
| 마스터관리자 | 시스템 전권 | 시스템 관리자 |
| HR | 인사·근태 전담 | 인사팀 실무자 |
| 산업안전관리자 | 안전 전담 | 산업안전 담당자 |

#### 8.2.2 권한 단위 구조

각 권한은 메뉴 항목별로 다음 속성을 설정한다.

| 속성 | 값 | 설명 |
| --- | --- | --- |
| 사용여부 | 사용 / 미사용 | 해당 메뉴 노출 여부 |
| 메뉴사용처 | WEB / APP / 둘 다 | 플랫폼별 노출 제어 |
| 조회 | 사용 / 미사용 | 목록·상세 조회 가능 여부 |
| 생성 | 사용 / 미사용 | 신규 등록 가능 여부 |
| 삭제 | 사용 / 미사용 | 삭제 가능 여부 |
| 저장 | 사용 / 미사용 | 수정·저장 가능 여부 |
| 엑셀 | 사용 / 미사용 | 엑셀 다운로드·업로드 가능 여부 |

#### 8.2.3 운영 원칙

- 마스터관리자 권한은 삭제·비활성화 불가

- 권한 변경 시 현재 로그인 중인 사용자는 다음 세션부터 반영

- 권한 변경 이력은 모두 보존

### 8.3 사업장 권한 관리

#### 8.3.1 개념

화면 권한(Role)과 별개로, 사용자가 접근 가능한 사업장 목록을 별도 매핑한다. 소속 사업장은 자동으로 접근 가능하며, 그 외 사업장은 명시적 부여가 필요하다.

#### 8.3.2 관리 방식

- 사용자 리스트에서 대상 선택

- 사업장 리스트에서 접근 허용할 사업장 선택 → 권한을 갖고 있는 사업장 영역으로 이동

- 저장 시 즉시 반영

#### 8.3.3 사업장 전환(Site Switcher)

- 복수 사업장 권한을 가진 사용자는 모바일 앱 상단에서 현장 전환 가능

- 전환 시 해당 사업장 컨텍스트로 완전 격리(조직도·데이터 모두 전환)

### 8.4 조직 스코프 규칙

소속 사업장과 타 사업장에서 접근 범위가 다르게 적용된다. 이는 PRAFTA의 핵심 권한 원칙이다.

#### 8.4.1 소속 사업장 내

- 조회 범위: 자기 부서 노드와 그 하위(자손) 노드

- 관리 권한(생성/수정/삭제/승인): 해당 노드에 담당 정 또는 담당 부로 지정된 경우에만 가능

- 단순 소속원은 자기 부서 범위 내 조회만 가능

#### 8.4.2 타 사업장 (사업장 권한 부여받은 경우)

- 조회 범위: 해당 사업장의 전 부서

- 관리 권한: 해당 사용자에게 부여된 화면 권한(CRUD)에 따라 결정

- 즉, 타 사업장에서는 조직 직급과 무관하게 화면 권한만으로 판단

#### 8.4.3 설계 의도

여러 사업장 권한 보유는 이례적이며, 본사 → 지사 방향의 감독 포지션을 상정한 설계다. 시스템에는 사업장 간 위계 필드를 두지 않으며, 위 규칙을 통해 자연스럽게 본사-지사 운영 패턴이 구현된다.

#### 8.4.4 적용 매트릭스

| 시나리오 | 화면 권한 | 사업장 권한 | 접근 결과 |
| --- | --- | --- | --- |
| 소속, 담당 정/부 | 승인 저장 가능 | A사업장 | A사업장 자기부서+하위 승인 가능 |
| 소속, 일반 소속원 | 승인 조회 가능 | A사업장 | A사업장 자기부서+하위 조회만 가능 |
| 타 사업장 | 승인 저장 가능 | A, B사업장 | B사업장 전 부서 승인 가능 |
| 타 사업장 | 승인 조회만 | A, B사업장 | B사업장 전 부서 조회만 가능 |
| 타 사업장 | 화면 권한 없음 | A, B사업장 | B사업장 해당 화면 접근 불가 |

### 8.5 마스터관리자 예외

- 마스터관리자는 조직 스코프 규칙을 넘어 전 사업장·전 부서·전 화면 접근

- 단, 사업장 권한 관리에서 접근 가능 사업장이 명시적으로 설정되어야 함

- 기본적으로 전 사업장이 자동 매핑됨
