## 6. 사업장 관리

### 6.1 사업장 구성 요소

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 사업장번호 | 필수 | 사업장 고유 코드 |
| 사업장명 | 필수 | 표시명 |
| 주소 / 상세주소 | 필수 | 지오펜스 중심 좌표 산출의 기준 |
| GPS 허용범위 | 선택 | 지오펜스 반경(미터). 미설정 시 GPS 판정 미사용 |
| 사용여부 | 필수 | 사용 / 미사용 |
| 사업개시일 / 사업종료일 | 선택 | 사업장의 운영 기간. 종료일 경과 시 자동 비활성화 처리 가능 |

### 6.2 GPS 허용범위 정책

- 사업장별로 독립 설정(예: 중곡사업장 200m, 테스트사업장 500m)

- 0 또는 미설정 시 해당 사업장은 GPS 지오펜스 판정을 사용하지 않음

- 모바일 출퇴근 시 이 범위를 기준으로 지오펜스 판정(사업장 내부/외부)

- GPS 관련 세부 정책은 근태관리 정책서 참조
