## 2. 시스템 구조

### 2.1 플랫폼 구성

| 플랫폼 | 주 사용자 | 주요 역할 |
| --- | --- | --- |
| 웹 (관리자) | 관리자 | 마스터 데이터 관리, 조직/권한 설정, 승인, 마감, 리포트 |
| 모바일 웹앱 (관리자) | 현장 관리자 | 출퇴근, 승인, 현장 점검, TBM 실시, 위험성평가 |
| 모바일 웹앱 (사용자) | 근로자 | 출퇴근, 요청 상신, 점검 참여, TBM 참석, 위험성평가 실시 |

### 2.2 플랫폼별 기능 제어

동일 권한이라도 플랫폼(WEB/APP)에 따라 화면 노출·액션 허용 여부를 개별 제어할 수 있다. 상세는 8.2절 참조.
