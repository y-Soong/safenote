## 13. 공통 UI/UX 원칙

### 13.1 디자인 가이드 참조

UI/UX의 세부 규칙은 별도 디자인 가이드 문서를 따른다. 본 정책서에서는 정책 수준의 원칙만 명시한다.

### 13.2 핵심 원칙

- 중립 베이스 + 상태색(Primary Green #16A34A, Danger #EF4444) 강조

- 메인 컨텐츠는 White, Header/LNB는 Primary Tint로 후퇴

- 모바일: 최대 390px 너비, 최소 44px 터치 영역

- 피드백: Toast(우측 하단), Alert(인라인), Badge

- z-index는 가이드 정의 범위 내에서만 사용

### 13.3 공통 인터랙션 원칙

- 승인/반려/삭제 등 되돌릴 수 없는 액션은 항상 **확인 모달**을 사용한다. 본 모달은 브라우저 네이티브 confirm이 아닌 서비스 톤앤매너의 커스텀 dialog(role="dialog", aria-modal="true")로 구현한다.

- 일괄 처리 시 선택 개수·영향 범위 명시

- 차단 상황(본인 결재/마감/선점/권한 없음, 사업장 미조회·종료 등 전제 미충족)은 명확한 배지와 배너로 표시

- 처리 이력은 타임라인 형태로 시각화
