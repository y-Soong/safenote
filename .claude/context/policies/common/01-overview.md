## 1. 개요

### 1.1 목적

본 문서는 PRAFTA(근태관리)와 SAFETY NOTE(산업안전관리) 모듈이 공통으로 참조하는 기반 정책을 정의한다. 두 모듈의 중복을 제거하고 시스템 전반의 뼈대를 일관되게 운영하는 것을 목적으로 한다.

### 1.2 적용 범위

- 전 임직원(정규/비정규직), 현장 근로자, 관리자, 시스템 관리자

- 일일계정으로 발급된 임시 사용자

- 웹(관리자) 및 모바일 웹앱(관리자/근로자) 전 채널

### 1.3 정책서 간 관계

본 정책서는 기반 정책을 정의하며, 다음 두 정책서가 본 문서를 참조한다.

- PRAFTA 근태관리 정책서

- PRAFTA 산업안전관리 정책서

권한·조직·사업장·계정·인증 등 공통 주제는 본 문서에서만 정의하며, 하위 정책서는 참조 형태로 연결한다.

### 1.4 용어

| 용어 | 정의 |
| --- | --- |
| 사업장 | 시스템의 최상위 격리 단위. 조직도·사용자·데이터는 사업장 단위로 분리된다. |
| 조직도(트리) | 사업장 하위에 고객이 자유 정의하는 계층 구조. |
| 조직 노드 | 조직도의 단위(본부/부/팀 등 명칭·레벨은 고객 자율). |
| 담당 정 / 담당 부 | 노드에 지정된 정·부 관리자. 해당 노드 소속자에 대한 운영 권한 보유. |
| 자체근태승인여부 | 노드에서 스스로 근태·휴가·추가근무를 승인할 수 있는지 여부를 결정하는 체크박스. |
| 권한(Role) | 메뉴 × CRUD × 플랫폼 조합으로 정의된 화면 접근 단위. |
| 사업장 권한 | 사용자가 접근 가능한 사업장 목록. |
| 계정 슬롯 | 사업장별로 사전 할당된 일일계정용 자리. 요금제 기반으로 총량이 결정된다. 슬롯 상태는 "빈 자리 / 사용 중"으로 표기한다(내부 상태값: empty / on). |
| 일일계정 | 비정규직·일용직을 위한 임시 계정. QR로 발급. 기본 수명 1일, 관리자의 점유 유지로 다일 연장 가능. |
| 점유 유지 | 슬롯의 자정 만료 배치 제외 플래그. ON 시 자정 만료에서 제외(다일 고용자 대응). 내부 상태값: hold. |
| 계정 등록 | 사업장별 일일계정 발급 기능의 on/off 토글. OFF 시 본 사업장의 모든 발급 경로(직접가입·관리자 QR 즉석 발급)가 차단된다. 기존 점유 슬롯은 §5.6 수명 규칙을 그대로 따른다. |
| 선점(처리 잠금) | 복수 관리자의 동일 건 동시 처리를 방지하는 잠금 방식. |
