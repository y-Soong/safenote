## 5. 일일계정 및 슬롯 관리

### 5.1 개념

비정규직·일용직은 현장마다 매일 바뀌는 유동 인력이다. 이들을 정규 회원가입 방식으로 일일이 등록/탈퇴 처리하는 것은 비효율적이므로, 사업장별로 사전 할당된 슬롯을 일일계정이 점유하는 구조로 운영한다.

본 장에서 정의된 정책의 집행 화면은 **"****일일계정관리****"** 화면이다(IA 단일 명칭 기준).

### 5.2 슬롯 개념 및 기본 수명

- 사업장별로 슬롯 N개가 사전 할당됨(예: 중곡사업장 10슬롯)

- 슬롯 1개 = 일일계정 1개가 임시로 차지하는 자리

- 슬롯이 모두 점유되면 신규 일일계정 발급 차단

- 일일계정의 기본 수명은 1일 (발급 당일 자정까지)

- 자정 배치에서 만료 처리 → 계정 삭제 → 슬롯 빈 자리 상태로 복귀

- 관리자가 **점유 유지**를 ON으로 설정한 슬롯은 자정 배치에서 제외 (다일 고용자 대응)

### 5.3 슬롯 총량 — 요금제 기반 및 사업장별 조정

- 전사 슬롯 총량은 고객사 계약 시 요금제에 따라 결정됨

- 마스터관리자는 요금제 총량 범위 내에서 사업장별 슬롯 수를 자유롭게 배분

- **사업장별 최대 슬롯 수**는 일일계정관리 화면의 운영 설정 영역에서도 직접 조정할 수 있으며, 이때의 조정 권한은 본 화면 자체에 대한 접근 권한과 동일하다(별도 권한 토큰 없음). 권한 부여는 §8 권한 체계 및 사용자 관리 화면을 통해 수행한다.

- 조정 가능 범위는 다음을 모두 만족해야 한다.

- 상한: 사업장 잔여 요금제 한도 내

- 하한: 현재 점유 슬롯 수 (이미 사용 중인 슬롯 수보다 작게 설정 불가)

- 변경 이력은 §11.3 감사 로그 대상이다.

- 요금제 한도를 초과하는 증설은 계약 갱신 필요.

### 5.4 슬롯 구성 요소

| 항목 | 값 | 설명 |
| --- | --- | --- |
| 사업장 | 사업장 정보 | 슬롯이 소속된 사업장 |
| 슬롯번호 | 사업장 내 1부터 시작, 2자리 0패딩 표기(예: 01) | 사업장 내 슬롯 식별자 |
| 슬롯구분 | 직접가입 / 관리자 QR | 점유한 일일계정의 발급 경로(내부 코드: self / qr) |
| 슬롯상태 | 빈 자리 / 사용 중 | 일일계정 매핑 여부 |
| 점유 유지 | on / off | ON 시 자정 만료 배치에서 제외(다일 고용자 대응) |
| 사용여부 | 사용 / 미사용 | 슬롯 자체의 활성화 여부 |
| 슬롯 점유자 | 사용자 정보 | 점유 중인 경우 해당 일일계정 사용자 |
| 슬롯점유 이력 | 이력 데이터 | 이 슬롯을 거쳐간 사용자 이력 |

**변경 사유**: ① 슬롯은 일일근로자 전용이므로 "일반 사용자" 구분이 불필요 ② "슬롯구분"은 발급 경로 식별 용도로 재정의

### 5.5 일일계정 발급

#### 5.5.1 발급 채널

| 항목 | 설명 |
| --- | --- |
| 계정 등록(토글) | 사업장별 일일계정 발급 기능의 on/off. OFF 시 본 사업장의 모든 발급 경로(직접가입·관리자 QR 즉석 발급)가 차단된다 |
| 활성화 계정 | 현재 사용 중인 슬롯 수 |
| 일일계정 회원가입 코드 | 사업장별 고유 코드(예: 001-00001) |
| 회원가입 QR | 사업장별 회원가입 페이지로 연결되는 QR. 현장 게시·공유 용도 |

#### 5.5.2 발급 경로

본 릴리스의 발급 경로는 두 가지이며, 각 경로별 특성은 다음과 같다.

| 경로(slotKind) | 매핑 방식 | 입력 항목 | 비고 |
| --- | --- | --- | --- |
| 직접가입 (self) | 자동 매핑(첫 번째 빈 슬롯에 자동 배정) | 근로자 본인이 회원가입 페이지에 정보 입력 | 회원가입 코드/QR로 진입. 빈 슬롯 없으면 발급 불가 안내 |
| 관리자 QR 즉석 발급 (qr) | 수동 매핑(관리자가 빈 슬롯을 직접 지정) | 관리자가 슬롯 + 근로자 이름 입력 | 일일계정관리 화면의 "관리자 QR 발급" 카드에서 진행. 1회용 QR 발급 후 근로자가 스캔하여 가입 완료 |

**참고**: 과거 근로자 재할당 기능은 본 릴리스에서 제외한다. 향후 재도입 시 §11(보안·개인정보)에 처리 근거 조항을 동시 신설할 것.

#### 5.5.3 발급 프로세스

- **직접가입**: 회원가입 코드/QR 입력 → 간소화된 가입 → 첫 번째 빈 슬롯에 자동 매핑

- **관리자 QR 즉석 발급**: 관리자가 빈 슬롯 + 근로자 이름 입력 → QR 생성 → 근로자가 스캔하여 가입 완료

- 두 경로 모두 회원가입은 필수 정보만 받는 간소화된 절차로 진행

- 기본 수명은 1일(발급 당일 자정까지). 다일 고용 예정이면 관리자가 해당 슬롯의 점유 유지를 ON으로 설정

- 슬롯 점유 시점·사용자 정보는 슬롯점유이력에 기록하며, 이때 발급 경로(slotKind)도 함께 저장

### 5.6 수명 및 만료 처리

#### 5.6.1 기본 수명

- 일일계정의 기본 수명은 1일(발급 당일 24:00까지)

- 자정 배치가 점유 유지가 OFF인 슬롯의 일일계정을 일괄 만료 처리

- 만료 = 계정 삭제 + 슬롯 빈 자리 복귀 (1회 동작)

- **표기 규칙**: 화면상 만료 시각은 24:00으로 표기한다. 실제 배치는 해당일 24:00 직후(=익일 00:00)에 실행된다.

#### 5.6.2 점유 유지 (다일 고용 대응)

- 점유 유지를 ON으로 설정한 슬롯은 자정 만료 배치에서 제외

- 점유 유지는 일일계정관리 화면에서 관리자가 직접 전환

- 발급 시점에 미리 ON 설정 또는 사후 전환 모두 가능 (당일 자정 배치 돌기 전까지 설정하면 다음날로 연결)

- ON인 동안에는 일일계정이 만료되지 않고 계속 사용 가능

- 관리자가 점유 유지를 OFF로 되돌리면 다음 자정 배치에서 만료 처리

- 점유 유지 ON/OFF 전환은 §11.3 감사 로그 대상이다.

#### 5.6.3 만료 처리 세부

- 만료 타이밍: 당일 자정에 실행되는 배치

- 처리 대상: 슬롯상태 = 사용 중 AND 점유 유지 = OFF 인 모든 슬롯

- 처리 내용: 일일계정 삭제 → 슬롯상태를 빈 자리로 전환

- 삭제된 계정은 복구 불가 (동일 인력 재사용 시 신규 발급 필요)

- 사용자의 활동 이력(출퇴근, 점검 참여 등)은 이력 데이터로 보존

- 슬롯점유 이력을 통해 해당 슬롯을 거쳐간 모든 사용자 추적 가능

#### 5.6.4 슬롯점유이력 조회

일일계정관리 화면의 "이력보기"는 슬롯점유이력을 조회하는 진입점이다. 다음 정책을 적용한다.

- 조회 가능 기간: **최대 1개월** (오늘 기준 −30일 cutoff)

- 조회 범위 내 모든 점유 레코드를 최신순으로 표시

- 종료 시점이 없는 레코드는 "점유 중"으로 표기

- 표시되는 사용자 정보(이름·연락처·기타 식별 항목)는 마스킹 처리한다.

- 마스킹 규칙은 §11 보안·개인정보 정책의 공통 마스킹 규정을 따른다.

- 정책 미정의 항목은 화면 운영 가이드에서 보완하되, 다음 기본값을 적용:

- 이름: 가운데 글자 마스킹 (예: 김○○)

- 연락처(존재 시): 가운데 4자리 마스킹 (예: 010-****-1234)

- 본 이력은 §11.3 감사 로그와 별개의 도메인 기록이며, 보존 기간은 §11(보안·개인정보) 일반 규정을 따른다.

### 5.7 제약 및 차단

- **슬롯 전량 점유 시**: 두 발급 경로 모두 신규 발급 차단, UI에서 명확히 안내

- **계정 등록 토글이 OFF**일 때: 두 발급 경로 모두 신규 발급 차단(직접가입 링크 진입 시 안내, 관리자 QR 발급 카드 비활성화). 기존 점유 슬롯은 §5.6 수명 규칙을 그대로 따른다.

- **사업장 종료일 경과**: 슬롯 자체 비활성화. 점유 중이던 일일계정은 점유 유지 여부와 무관하게 자동 삭제. 화면 상단에 "사업장 종료 — 슬롯 운영 중지됨" 배너를 노출한다(§13.3 차단 상황 표시 원칙 준수).

- **사업장 미조회 상태**(화면 진입 직후): 운영 설정/발급 카드/테이블 영역을 잠금 처리하고, "사업장을 먼저 조회해주세요" 안내 배너를 함께 노출한다.
