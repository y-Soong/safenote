## 3. 계정 및 인증

### 3.1 회원가입

- 필수 입력: 회사코드, 아이디(410자), 비밀번호(615자), 이름, 휴대폰, 사업장, 생년월일

- 선택 입력: 이메일, 성별

- 약관 동의: 이용약관/개인정보/위치기반(필수), 마케팅(선택)

- 정규 회원가입은 슬롯 체계와 무관(5장 참조)

### 3.2 로그인

- 아이디/비밀번호 기반

- 아이디 저장 옵션 제공

- 최초 로그인 시 권한에 따라 진입 화면이 분기된다

### 3.3 계정 찾기 / 비밀번호 재설정

- 이름 + 휴대폰 본인인증 → 아이디 표시 또는 비밀번호 재설정

- 재설정된 비밀번호로 로그인 후 즉시 변경 권장

### 3.4 세션 관리

- 로그아웃·세션 종료·브라우저 종료 시 선점(처리 잠금)은 즉시 해제된다(9장 참조)

- 로그인 시 액세스 토큰(유효기간 1시간)과 리프레쉬 토큰(유효기간 48시간)을 함께 발급한다

- 액세스 토큰 만료 후 리프레쉬 토큰이 유효한 상태에서 앱을 재실행하면 액세스 토큰이 자동 갱신된다

- 리프레쉬 토큰까지 만료된 경우 재로그인이 필요하다

### 3.5 계정 상태

| 상태 | 설명 | 허용 동작 |
| --- | --- | --- |
| 활성화 | 정상 사용 가능 | 전 기능 접근 |
| 미사용 | 관리자가 비활성화 | 로그인 차단 |
| 탈퇴 | 탈퇴 처리됨 | 로그인 차단, 이력만 조회 가능 |
