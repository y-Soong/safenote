## 7. 조직 관리

### 7.1 조직 구조 원칙

- 사업장 단위로 독립된 조직도를 갖는다

- 최상위 노드는 사업장 자신(예: 중곡사업장)

- 하위 노드는 고객이 자유 정의(본부/부/팀 등)

- 모든 사용자는 정확히 하나의 노드에 소속된다(1인 1소속)

### 7.2 노드 관리자 — 담당 정/부

- 각 노드는 담당 정(필수), 담당 부(선택)를 지정할 수 있다

- 담당 정/부로 지정된 사용자의 소속 부서는 해당 노드로 자동 변경된다

- 담당 정/부는 해당 노드 소속자에 대한 관리 권한을 갖는다(근태 승인, 휴가 승인, 안전 관리 등)

- 동일 노드에 복수 관리자가 있으면 병렬 처리 방식(누구든 1명이 처리하면 종결), 동시 처리는 선점으로 방지(9장)

### 7.3 자체근태승인여부

노드별 체크박스로 관리한다. 해당 노드에서 스스로 근태·휴가·추가근무를 승인할 수 있는지 여부를 결정한다.

| 설정 | 동작 |
| --- | --- |
| 체크 ON | 해당 노드의 담당 정/부가 자기 노드 소속자의 근태를 직접 승인 가능 |
| 체크 OFF | 해당 노드의 근태 승인 권한이 상위 노드의 담당 정/부로 위임됨 |

세부 적용 규칙(승인 경로, 자기 승인 예외 등)은 근태관리 정책서를 따른다.

### 7.4 타사업장 조직부서 가져오기

- 타사업장의 조직 구조를 현재 사업장에 복제하는 기능

- 구조만 복제되며 담당 정/부 지정은 복제되지 않음

- 복제 후 현재 사업장의 사용자를 재배치해야 함

### 7.5 조직부서 일괄 삭제

- 사업장의 조직 구조를 초기화하는 기능

- 소속 사용자가 있는 노드는 삭제 불가(사전에 사용자 이동 필요)

### 7.6 소속 사업장 단일성

- 모든 사용자는 정확히 하나의 소속 사업장을 갖는다

- 소속 사업장 변경은 미결 업무(대기 요청, 선점, GPS 미확인) 해소 후 가능

- 소속 사업장과 사업장 권한은 별개 개념(8.3절 참조)
