## 11. 보안 · 개인정보 · 위치정보

### 11.1 기본 원칙

- 목적 제한: 수집된 정보는 정책서에 명시된 목적으로만 사용

- 최소 수집: 기능 수행에 필요한 최소 정보만 수집

- 최소 권한: 업무 수행에 필요한 최소 권한만 부여

- 이력 보존: 중요 변경은 모두 감사 로그로 보존

### 11.2 위치정보 처리

- 위치는 출퇴근 등록 시점에만 최소 처리(상시 추적 금지)

- GPS 미확인은 등록 허용하되 확인 필요 상태로 관리(근태 정책서 참조)

- 상세 위치 조회는 별도 권한으로 제한

### 11.3 감사 로그

다음 행위는 누가/언제/무엇을/왜의 형태로 로그를 남긴다.

- 권한 변경, 사업장 권한 변경

- 조직 구조 변경(노드 생성/삭제, 담당 정/부 지정)

- 사용자 상태 변경(활성화/미사용/탈퇴)

- 다운로드, 상세 위치 조회

- 중요 데이터 삭제

- **일일계정관리 화면 액션**: 점유 유지 ON/OFF 전환, 슬롯 비우기, 최대 슬롯 수 변경, 계정 등록 토글 ON/OFF 전환
