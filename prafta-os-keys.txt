[범례]
 (필수)        = 기본값 없음. 미설정 시 앱 기동 실패.
 (선택/기본값) = 미설정 시 괄호 안 기본값 사용.
 (게이트)      = on/off 스위치. 기본 off. @Value 기동 시 1회 바인딩 → 변경 후 재시작 필요.
 (시크릿)      = 자격증명/암호화키. 커밋·로그 출력 금지.

 B. 환경변수로 "선언"되진 않았으나 OS 환경변수로 override 가능한 프로퍼티
    (현재는 application.properties 하드코딩 기본값 또는 @Value 인라인 기본값 사용.
     Spring relaxed-binding: 점/하이픈 → 대문자_언더스코어 환경변수로 덮어쓰기 가능)
────────────────────────────────────────────────────────────────────────────────

JWT_EXPIRATION                    # → jwt.expiration (현재 3600000=1시간). application.properties:14
LOGIN_LOCK_DURATION_MINUTES       # → login.lock.duration-minutes (현재 3분). application.properties:17
LOGIN_LOCK_MAX_FAIL_COUNT         # → login.lock.max-fail-count (현재 5회). application.properties:18
SECURITY_PASSWORD_BCRYPT_STRENGTH # → security.password.bcrypt.strength (현재 12). application.properties:21
SECURITY_PASSWORD_RANDOM_BYTE_LENGTH # → security.password.random.byte-length (현재 24). application.properties:27

# --- @Value 인라인 기본값만 존재(application.properties 에 미선언) 게이트 2종 ----
PRAFTA_LEAVE_AUTO_GRANT_ENABLED   # (게이트, 기본 false) → prafta.leave.auto-grant.enabled. 연차 자동부여 배치 on/off.
PRAFTA_NOTICE_ACK_CLEANUP_ENABLED # (게이트, 기본 false) → prafta.notice.ack-cleanup.enabled. 공지 확인이력 정리 배치 on/off.

# --- 프로필 전환(표준 Spring) ---------------------------------------------------
SPRING_PROFILES_ACTIVE            # → spring.profiles.active (현재 local). dev/prod 프로필 전환 시.
                                  #   ※ dev/prod 프로필 파일에는 ${ENV} 주입이 없음(DB 등 하드코딩) — 운영 배포 시 확인 필요.
